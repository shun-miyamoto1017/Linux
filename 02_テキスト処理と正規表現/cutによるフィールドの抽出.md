## cutとは

**`cut` はテキストファイルの各行から、指定した部分を取り出して表示するコマンド**です。

```text
cut {-b | -c | -f} リスト [そのほかのオプション] [ファイル名]
```

**`-b` `-c` `-f` のどれか 1 つは必須**です。省略するとエラーになります。

```bash
$ cut pw.txt                          # 何を取り出すか指定していない
cut: you must specify a list of bytes, characters, or fields
$ echo $?                             # 終了ステータスは 1
1
```

**取り出し方は 2 通り**あります。

```text
   ① フィールド単位   -d で区切り文字を決め、-f で何番目かを指定する
   ② 文字位置単位     -c で「何文字目から何文字目まで」を指定する
```

**ファイル名を省略すると標準入力から読みます。** パイプの途中に置けます。

---

## よく使うオプション

| オプション | 意味 |
|:--|:--|
| **`-d 区切り文字`** | **フィールドの区切り文字を指定する**（delimiter）。**既定はタブ** |
| **`-f フィールド`** | **取り出すフィールドを番号で指定する**（field） |
| **`-c 文字位置`** | **取り出す位置を指定する**（character）。**GNU 実装では実際はバイト単位**（後述） |
| `-b バイト位置` | バイト位置で指定する（byte）。**GNU では `-c` と同じ動き** |
| `--complement` | 指定した以外を取り出す（反転） |
| `--output-delimiter=文字` | 出力するときの区切り文字を変える |

**`-f` と `-c` は同時に使えません。** どちらか一方です。

## フィールドで切り出す

```bash
$ cat pw.txt                          # : 区切りのファイル
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin

$ cut -d : -f 1,7 pw.txt              # 1番目と7番目のフィールドを取り出す
root:/bin/bash
daemon:/usr/sbin/nologin
bin:/usr/sbin/nologin
```

**引数の位置を取り違えないでください。**

```text
   cut  -d  :  -f  1,7  pw.txt
        │   │  │   │    │
        │   │  │   │    └─ ファイル名
        │   │  │   └────── 何番目のフィールドか
        │   │  └────────── 「フィールド指定です」という合図
        │   └───────────── 区切り文字そのもの
        └───────────────── 「区切り文字指定です」という合図
```

| 書き方 | 正しいか |
|:--|:--|
| **`cut -d : -f 1,7 pw.txt`** | **○** |
| `cut -d 1,7 -f : pw.txt` | **✕** `-d` と `-f` の引数が入れ替わっている |
| `cut -f 1,7 -d : pw.txt` | ○（**順番は前後してもよい**。引数さえ正しく対応していれば動く） |

### 区切り文字の既定はタブ

**`-d` を省略すると、区切り文字はタブとして扱われます。**

```bash
$ cut -f 1,7 pw.txt                   # -d を忘れると区切りはタブ扱い
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
```

**行がそのまま出てきました。**
**区切り文字を 1 つも含まない行は、`-f` で何番を指定していても
そのまま出力される**、という `cut` の仕様のためです。

```bash
$ cut -f 2 pw.txt                     # 1番目を選んでいなくても結果は同じ
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
```

**エラーにならず、黙って全部出る**のが怖いところです。
**`:` 区切りや `,` 区切りを扱うときは `-d` を必ず付けてください。**

**補足 … タブが無い行は既定で丸ごと出ます**

区切り文字を含まない行は、**そのまま出力されます**。
除きたいときは **`-s`（`--only-delimited`）** を付けます。

```bash
$ printf 'a:b\nnodelim\n' | cut -d : -f 1      # 区切りの無い行もそのまま出る
a
nodelim
$ printf 'a:b\nnodelim\n' | cut -d : -f 1 -s   # -s なら区切りの無い行は捨てる
a
```

### フィールドの指定方法

| 書き方 | 意味 |
|:--|:--|
| **`-f 3`** | **3 番目だけ** |
| **`-f 1,7`** | **1 番目と 7 番目**（カンマ区切りで複数） |
| **`-f 1-3`** | **1 番目から 3 番目まで**（範囲） |
| **`-f 3-`** | **3 番目から最後まで** |
| **`-f -3`** | **最初から 3 番目まで** |

```bash
$ cut -d : -f 1-3 pw.txt              # 1番目から3番目まで
root:x:0
daemon:x:1
bin:x:2
$ cut -d : -f 3- pw.txt               # 3番目から最後まで
0:0:root:/root:/bin/bash
1:1:daemon:/usr/sbin:/usr/sbin/nologin
2:2:bin:/bin:/usr/sbin/nologin
```

**補足 … 並べ替えはできません**

**`-f 7,1` と書いても、出力は元の順（1 番目→7 番目）**になります。
`cut` は「取り出す」だけで、**列を並べ替える機能はありません**。
並べ替えたいときは `awk` を使います。

**補足 … 出力の区切りを変える**

**既定では、入力と同じ区切り文字で出力**されます。
変えたいときは `--output-delimiter` を使います。

```bash
$ cut -d : -f 1,7 --output-delimiter=' -> ' pw.txt   # 出力の区切りを変える
root -> /bin/bash
daemon -> /usr/sbin/nologin
bin -> /usr/sbin/nologin
```

## 文字位置で切り出す

**`-c` は「何文字目か」で切り出します。** 区切り文字は関係ありません。

**重要 … GNU の `-c` は実際にはバイト単位です。**
**日本語のようなマルチバイト文字が混ざると、文字数では切れません。**

```bash
$ cat jp.txt                          # 全角5文字の行と、半角5文字の行
あいうえお
abcde
$ cut -c 1-3 jp.txt | head -1 | od -c   # 3文字ではなく3バイト＝「あ」1文字だけ
0000000 343 201 202  \n
0000004
$ cut -c 1-1 jp.txt | head -1 | od -c   # 1バイトだけ取ると文字が壊れる
0000000 343  \n
0000002
```

**ロケールを変えても結果は同じ**で、`-b` と `cmp` しても差分は出ませんでした（実測）。
**日本語を含む行に `-c` を使ってはいけません。** `awk` の `substr()` を使ってください。

```bash
$ cut -c 1-4 pw.txt                   # 各行の1文字目から4文字目まで
root
daem
bin:
```

**桁が固定されている出力に向いています。**

```bash
$ ls -l /etc/hosts                    # パーミッションは必ず先頭10文字
-rw-r--r-- 1 root root 174 Sep 19 15:30 /etc/hosts
$ ls -l /etc/hosts | cut -c 1-10      # パーミッション部分だけを取り出す
-rw-r--r--
```

| | **`-c`** | **`-f`** |
|:--|:--|:--|
| 基準 | **バイトの位置**（名前に反して文字ではない） | **区切り文字で分けたまとまり** |
| 向いている入力 | **桁が固定された ASCII の出力** | **`:` や `,` で区切られたファイル** |
| 桁がずれたら | **壊れる** | 影響を受けない |
| **日本語が混ざると** | **使えない**（文字が割れる） | 影響を受けない |

## passwdファイルを読む

**`/etc/passwd` は `cut` の練習台としてよく出てきます。**
**`:` 区切りで 7 つのフィールド**があります。

```text
   root : x : 0 : 0 : root : /root : /bin/bash
    ①    ②   ③   ④    ⑤      ⑥        ⑦
```

| 番号 | 中身 |
|:-:|:--|
| **①** | **ユーザ名** |
| ② | パスワード（`x` は `/etc/shadow` にあるという印） |
| **③** | **UID**（ユーザ識別子） |
| ④ | GID（グループ識別子） |
| ⑤ | コメント（氏名など） |
| ⑥ | ホームディレクトリ |
| **⑦** | **ログインシェル** |

```bash
$ cut -d : -f 1,7 /etc/passwd | head -3    # ユーザ名とログインシェルの一覧
root:/bin/bash
daemon:/usr/sbin/nologin
bin:/usr/sbin/nologin
```

**`/sbin/nologin` や `/usr/sbin/nologin` はログインできないアカウント**です。
サービス専用のシステムユーザに設定されています。

```bash
$ cut -d : -f 1,7 /etc/passwd | grep -v nologin   # ざっくり nologin を除く
```

**ただし、これは簡易版**です。**2 つの取りこぼしがあります。**

| 取りこぼし | 例 |
|:--|:--|
| **`nologin` 以外のログイン不可シェルが残る** | `/bin/false` `/bin/sync` |
| **ユーザ名に `nologin` を含むと誤って消える** | `nologinadmin` |

**正確にやるなら `awk` で 7 番目のフィールドだけを見ます。**

```bash
$ awk -F : '$7 !~ /(nologin|false|sync)$/ {print $1":"$7}' /etc/passwd   # 7番目だけを見る
```

## cut が苦手なこと

**空白区切りのテキストは苦手**です。**空白が連続していると空のフィールドが生まれる**ためです。

```bash
$ printf 'a   b   c\n' | cut -d ' ' -f 2 | cat -A   # 空白3つ … 2番目は「空」になる
$
```

**空行が 1 行出ただけ**でした。`a` と `b` の間に空白が 3 つあるので、
**フィールドは `a` / 空 / 空 / `b` …** と数えられ、2 番目は空文字になります。

**解決策は 2 つ**あります。

```bash
$ printf 'a   b   c\n' | tr -s ' ' | cut -d ' ' -f 2   # ① tr -s で空白を詰めてから
b
$ printf 'a   b   c\n' | awk '{print $2}'              # ② awk を使う
b
```

**`awk` は空白の連続を 1 つの区切りとして扱う**ので、
**空白区切りは最初から `awk` のほうが素直**です。

## pasteで横につなぐ

**`cut` が「縦に切る」なら、`paste` は「横に貼る」**コマンドです。
**複数のファイルを行単位で結合**します。

```text
paste [-d 区切り文字] [-s] [ファイル名 ...]
```

```bash
$ cat f1                              # 1つ目のファイル
Monday
Tuesday
Wednesday
$ cat f2                              # 2つ目のファイル
月曜日
火曜日
水曜日
$ paste f1 f2                         # 行単位で横に結合する
Monday	月曜日
Tuesday	火曜日
Wednesday	水曜日
```

**既定の区切り文字はタブ**です。`cut -d` と同じく、**タブが既定**という点をそろえて覚えてください。

**`-d` で区切り文字を変えられます。**

```bash
$ paste -d : f1 f2                    # コロンで結合する
Monday:月曜日
Tuesday:火曜日
Wednesday:水曜日
```

| オプション | 意味 |
|:--|:--|
| **`-d 文字`** | **区切り文字を指定する**（既定はタブ） |
| **`-s`** | **1 つのファイルの全行を、1 行に横並びにする**（serial） |

```bash
$ paste -s f1                         # 縦に並んでいた3行を1行にする
Monday	Tuesday	Wednesday
```

**`cat` との違い**

| | **`cat f1 f2`** | **`paste f1 f2`** |
|:--|:--|:--|
| つなぎ方 | **縦**（f1 の後ろに f2） | **横**（同じ行番号どうし） |
| 区切り文字の指定 | **できない**（`-d` は無い） | **`-d` でできる** |

**`cat -d` というオプションはありません。** 試験では誤答として出ます。

**補足 … 1つのファイルを何列かに折り返す**

**`-` を並べると、標準入力から「その数ずつ」取り出して 1 行にします。**

```bash
$ paste - - < f1                      # 2つずつ取り出して1行にする
Monday	Tuesday
Wednesday
```

**3 行を 2 つずつ取ったので、最後の行は 1 つだけ**になりました。
**足りない分は空文字で埋められる**ので、**末尾に区切り文字（タブ）が 1 つ残ります。**

```bash
$ paste - - < f1 | cat -A             # 制御文字を見えるようにする
Monday^ITuesday$
Wednesday^I$                          ← 末尾にタブが残っている
```

## awk との使い分け

| | **`cut`** | **`awk`** |
|:--|:--|:--|
| 区切りの既定 | **タブ** | **空白の並び**（連続もまとめて 1 つ） |
| 空白が連続したら | **空のフィールドができる** | **1 つの区切りとして扱う** |
| 列の並べ替え | **できない** | **できる**（`{print $7, $1}`） |
| 条件で絞る | できない | **できる**（`$3 > 1000 {print}`） |
| 計算 | できない | **できる** |
| 速さ | **速い** | 機能ぶん遅い |
| 覚えることの量 | **少ない** | 多い（小さな言語） |

**「`:` 区切りや `,` 区切りから列を抜くだけ」なら `cut`**、
**「空白区切り・並べ替え・条件・計算」が要るなら `awk`** と使い分けます。

```bash
$ cut -d : -f 1,7 /etc/passwd              # cut … 単純な抜き出し
$ awk -F : '$3 >= 1000 {print $1}' /etc/passwd   # awk … UID 1000 以上のユーザ名だけ
```

## 実務での組み合わせ

| やりたいこと | 書き方 |
|:--|:--|
| **一般ユーザの一覧を作る** | `awk -F : '$3 >= 1000 {print $1}' /etc/passwd` |
| **ログインシェルの種類を数える** | `cut -d : -f 7 /etc/passwd \| sort \| uniq -c \| sort -rn` |
| **CSV の特定列だけ取り出す** | `cut -d , -f 2,5 data.csv` |
| **マウント済みデバイスの一覧** | `mount \| cut -d ' ' -f 1` |
| **アクセスログの IP を数える** | `cut -d ' ' -f 1 access.log \| sort \| uniq -c \| sort -rn \| head` |
| **プロセスの PID だけ取り出す** | `ps -eo pid=`（または `ps -e \| awk '{print $1}'`） |

**注意 … `tr -s` ＋ `cut` は右詰めの出力に使えません**

「`tr -s ' '` で空白を詰めてから `cut`」という書き方をよく見かけますが、
**`ps` のように列が右詰めの出力では壊れます。**

```bash
$ cat pssim.txt                       # PID が右詰めになった ps 風の出力
  PID TTY          TIME CMD
12345 ?        00:00:01 bigproc
    1 ?        00:00:00 init
$ tr -s ' ' < pssim.txt | cut -d ' ' -f 2    # 2番目を取ると…
PID
?                                     ← PID ではなく TTY が出た
1
$ awk '{print $1}' pssim.txt          # awk なら常に正しい
PID
12345
1
```

**行頭に空白があるかどうかでフィールド番号がずれる**のが原因です。
`ps` の PID 列は最大 PID の桁数で幅が決まるため、
**5 桁の PID が混ざった瞬間に、エラーも出さずに違う値を返します。**

**`awk` は先頭の空白を区切りとして捨てる**ので、この問題が起きません。
**右詰めの出力を扱うときは `awk`**、と覚えてください。
