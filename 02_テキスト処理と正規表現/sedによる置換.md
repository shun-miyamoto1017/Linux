## sedとは

**`sed` は、ファイルや標準入力の内容を編集して表示するコマンド**です。
名前は **s**tream **ed**itor（ストリームエディタ）から来ています。

**`vi` との決定的な違いは「開かない」こと**です。

```text
   vi   … ファイルを画面に開いて、人が編集する
   sed  … ファイルを1行ずつ読み、指示どおり加工して出力する（画面を開かない）
```

**画面を開かないので、スクリプトに書ける・複数ファイルに一度に流せる**のが利点です。

**既定ではファイルを書き換えません。** 加工した結果を**標準出力に出すだけ**です。
書き換えたい場合は `-i` を使うか、リダイレクトで別ファイルに保存します。

---

## 書式

```text
sed [オプション] 'スクリプト' [ファイル名]
```

**スクリプトは `アドレス コマンド` の形**です。

```text
   sed '2d'              →  2行目を削除する
   sed '/^#/d'           →  # で始まる行を削除する
   sed 's/A/B/g'         →  全行で A を B に置換する（アドレス省略＝全行）
        └───┬───┘
        アドレスを省略すると全行が対象
```

| 部分 | 意味 |
|:--|:--|
| **アドレス** | **どの行を対象にするか**（行番号、範囲、正規表現）。省略すると**全行** |
| **コマンド** | **何をするか**（`s` 置換 / `d` 削除 / `p` 表示 / `i` `a` `c` 挿入・追加・置き換え） |

**スクリプトはシングルクォートで囲みます。**
中に `$` や `*` を書いたときにシェルへ横取りされないためです。

---

## よく使うオプション

| オプション | 意味 |
|:--|:--|
| **`-n`** | **自動出力をしない**。`p` コマンドと組み合わせて「必要な行だけ出す」 |
| **`-e スクリプト`** | **スクリプトを複数指定する** |
| **`-i[接尾辞]`** | **ファイルを直接書き換える**（接尾辞を付けるとバックアップを残す） |
| **`-E`** / **`-r`** | **拡張正規表現を使う** |
| `-f ファイル` | スクリプトをファイルから読み込む |
| `-s` | 複数ファイルを別々に扱う（行番号をファイルごとに数える） |
| `--posix` | GNU 拡張を無効にする |

**`-E` と `-r` は同じ**です。`-r` は GNU 独自、`-E` は BSD と共通なので、
**移植性を考えるなら `-E`** を使ってください。

## 置換する

**`s` コマンドが `sed` の中心**です。

```text
s/置換前/置換後/フラグ
```

確認に使うファイルはこれです。

```bash
$ cat sed.txt                         # 確認用のファイル
apple
banana
cherry
#comment
apple pie
```

```bash
$ sed 's/apple/APPLE/' sed.txt        # apple を APPLE に置換する
APPLE
banana
cherry
#comment
APPLE pie
```

**元のファイルは変わりません。** 画面に出ているのは加工した結果です。

### gを付けないとどうなるか

**`g` を付けないと、各行の最初に見つかった1つだけが置換対象**になります。

```bash
$ sed 's/a/A/' sed.txt                # 各行の最初の a だけを置換する
Apple
bAnana                                ← banana の2つ目以降の a は残る
cherry
#comment
Apple pie

$ sed 's/a/A/g' sed.txt               # 行内のすべての a を置換する
Apple
bAnAnA                                ← すべて置換された
cherry
#comment
Apple pie
```

| フラグ | 意味 |
|:--|:--|
| **（なし）** | **各行の最初の1つだけ** |
| **`g`** | **行内のすべて**（global） |
| **`数字`** | **各行の n 番目だけ** |
| `数字g` | 各行の n 番目以降すべて |
| **`i`** / `I` | **大文字小文字を区別しない** |
| **`p`** | **置換した行を表示する**（`-n` と組み合わせる） |
| `w ファイル` | 置換した行をファイルに書き出す |

### 何番目を置換するか指定する

```bash
$ sed 's/a/A/2' sed.txt               # 各行の2番目の a だけを置換する
apple
banAna                                ← 2つ目の a だけ変わった
cherry
#comment
apple pie
```

**`apple` に `a` は1つしか無い**ので、その行は変化していません。

### 区切り文字は変えられる

**`s` の直後の文字が区切り文字になります。** `/` でなくても構いません。

```text
   s/\/etc\/old/\/etc\/new/g      ← 読みにくい（バックスラッシュだらけ）
   s#/etc/old#/etc/new#g          ← # を区切りにすると読みやすい
   s|/etc/old|/etc/new|g          ← 縦棒でもよい
```

**パスを置換するときは区切りを変える**、と覚えておくと事故が減ります。

### 一致した文字列を使い回す

**`&` は「置換前にマッチした文字列そのもの」**を表します。

```bash
$ sed 's/apple/&s/' sed.txt           # マッチした apple の後ろに s を足す
apples
banana
cherry
#comment
apples pie
```

**`\( \)` で囲むと、その部分を `\1` `\2` で呼び出せます**（後方参照）。

```bash
$ sed 's/\(an\)\(an\)/[\1][\2]/' sed.txt   # 2つのグループに分けて囲む
apple
b[an][an]a
cherry
#comment
apple pie
```

**拡張正規表現なら `\( \)` の `\` が不要**になります。

```bash
$ sed -E 's/(an)(an)/[\1][\2]/' sed.txt    # -E なら括弧をそのまま書ける
apple
b[an][an]a
cherry
#comment
apple pie
```

**呼び出す側の `\1` `\2` は、`-E` を付けても `\` が必要**です。

## 行を削除する

**`d` コマンドで行を削除します。**

```bash
$ sed '2d' sed.txt                    # 2行目を削除する
apple
cherry
#comment
apple pie

$ sed '/^#/d' sed.txt                 # 「#」から始まる行を削除して出力する
apple
banana
cherry
apple pie

$ sed '$d' sed.txt                    # 最終行を削除する（$ が最終行を表す）
apple
banana
cherry
#comment
```

**設定ファイルからコメントと空行を落とす**のに使えます。

```bash
$ sed -e '/^#/d' -e '/^$/d' nginx.conf     # コメント行と空行を両方消す
```

## 行を表示する

**`p` コマンドは行を表示します。** ただし**`-n` とセットで使う**のが基本です。

```bash
$ sed -n '2p' sed.txt                 # 2行目だけを表示する
banana

$ sed -n '2,3p' sed.txt               # 2行目から3行目を表示する
banana
cherry

$ sed -n '/an/p' sed.txt              # an を含む行だけを表示する
banana
```

**`-n` を付けないと二重に出ます。**
`sed` は既定で**読んだ行をそのまま出力する**ので、`p` を足すと同じ行が 2 回出るためです。

```text
   sed 'p' file      →  全行が2回ずつ出る
   sed -n 'p' file   →  全行が1回ずつ出る（cat と同じ）
   sed -n '2p' file  →  2行目だけが出る
```

**`sed -n '/pattern/p'` は `grep pattern` と同じ**動きになります。
行の抽出だけなら `grep` のほうが速く読みやすいので、**`sed` は置換や加工が必要なときに使います**。

## 行を追加する

| コマンド | 意味 |
|:--|:--|
| **`i`** | **指定行の前に挿入する**（insert） |
| **`a`** | **指定行の後に追加する**（append） |
| **`c`** | **指定行を置き換える**（change） |

```bash
$ sed '2i INSERTED' sed.txt           # 2行目の前に挿入する
apple
INSERTED
banana
cherry
#comment
apple pie

$ sed '2a APPENDED' sed.txt           # 2行目の後に追加する
apple
banana
APPENDED
cherry
#comment
apple pie

$ sed '2c CHANGED' sed.txt            # 2行目を丸ごと置き換える
apple
CHANGED
cherry
#comment
apple pie
```

**設定ファイルの末尾に1行足す**なら `$a` を使います。

```bash
$ sed -i '$a MaxClients 256' httpd.conf    # 最終行の後ろに追記する
```

## アドレスの指定方法

**どの行を対象にするか**の書き方です。

| 書き方 | 対象 |
|:--|:--|
| **（省略）** | **全行** |
| **`3`** | **3行目** |
| **`2,5`** | **2行目から5行目** |
| **`$`** | **最終行** |
| **`/正規表現/`** | **マッチした行** |
| `2,$` | 2行目から最終行まで |
| `/start/,/end/` | `start` の行から `end` の行まで |
| `0~2` | 偶数行（GNU 拡張。`最初~間隔`） |
| `1~2` | 奇数行（GNU 拡張） |
| **`/正規表現/!`** | **マッチ「しない」行**（`!` で反転） |

```bash
$ sed '1~2d' sed.txt                  # 奇数行を削除する（GNU 拡張）
banana
#comment

$ sed '/^#/!d' sed.txt                # # で始まらない行を削除する（＝# の行だけ残す）
#comment
```

**`!` は「反転」**です。`grep -v` と同じ働きをします。

## ファイルを直接書き換える

**`-i` を付けると、標準出力ではなく元のファイルを書き換えます。**

```bash
$ cp sed.txt work.txt                 # 元ファイルは残したいので複製で試す
$ sed -i 's/apple/APPLE/' work.txt    # ファイルを直接書き換える（出力は出ない）
$ head -1 work.txt                    # 書き換わったことを確認する
APPLE
$ ls work.txt*                        # バックアップは作られていない
work.txt
```

**`-i` に接尾辞を付けると、バックアップが残ります。**

```bash
$ cp sed.txt work.txt                 # 元の内容に戻してから試す
$ sed -i.bak 's/apple/APPLE/' work.txt   # .bak 付きのバックアップを残して書き換える
$ ls work.txt*                        # 今度は .bak ができている
work.txt  work.txt.bak
$ head -1 work.txt                    # 書き換わったファイル
APPLE
$ head -1 work.txt.bak                # 元の内容が残っている
apple
```

**本番では必ず接尾辞を付けてください。** `-i` だけだと戻せません。

**手順としてはこの3段**です。

```bash
$ sed 's/old/new/g' nginx.conf            # ① まず画面で結果を確認する
$ diff <(sed 's/old/new/g' nginx.conf) nginx.conf   # ② 差分だけを見る
$ sed -i.bak 's/old/new/g' nginx.conf     # ③ 確認できたら書き換える
```

**補足 … `-i` の書き方は GNU と BSD で違います**

| 環境 | 書き方 |
|:--|:--|
| **GNU sed**（Linux） | **`sed -i.bak`**（接尾辞を続けて書く。空白を空けない） |
| **BSD sed**（macOS） | **`sed -i '.bak'`**（接尾辞を別の引数にする） |

**Linux 用に書いたスクリプトが macOS で動かない**、というのはこれが原因のことが多いです。

**補足 … `-i` は「その場で書き換える」わけではありません**

`sed -i` は内部で**一時ファイルを作り、書き終えてから元のファイル名に置き換えて**います。
そのため、**シンボリックリンクに対して実行するとリンクが実ファイルに置き換わります**
（GNU sed では `--follow-symlinks` で回避できます）。

## yコマンドで1文字ずつ置き換える

**`s` が「文字列」の置換なのに対して、`y` は「1 文字ずつの対応表」による置換**です。

```text
y/文字1文字2…/文字A文字B…/
```

**文字1 を 文字A に、文字2 を 文字B に**、というように **位置で対応**します。

```bash
$ cat t.txt                           # 確認用のファイル
abc
aab
$ sed 'y/ab/AB/' t.txt                # a を A に、b を B に置き換える
ABc
AAB
```

**`s/ab/AB/g` とは結果が違います。**

| 書き方 | 意味 | `aab` の結果 |
|:--|:--|:--|
| **`y/ab/AB/`** | **`a`→`A`、`b`→`B` と 1 文字ずつ** | **`AAB`** |
| `s/ab/AB/g` | **`ab` という 2 文字の並び**を `AB` に | `aAB`（先頭の `a` は残る） |

**同じことを `s` で書くなら、`-e` を 2 つ並べます。**

```bash
$ sed -e 's/a/A/g' -e 's/b/B/g' t.txt   # y/ab/AB/ と同じ結果になる
ABc
AAB
```

**注意 … 両側の文字数はそろえてください。**

```bash
$ sed 'y/ab/A/' t.txt                 # 左が2文字、右が1文字
sed: -e expression #1, char 7: strings for `y' command are different lengths
$ echo $?                             # 終了ステータスは 1
1
```

**`s` と違って、`y` には `g` フラグも正規表現もありません。**
**行内のすべての文字が、無条件に対応表で置き換わります。**

| | **`s`** | **`y`** |
|:--|:--|:--|
| 対象 | **正規表現にマッチした文字列** | **1 文字ずつ** |
| 正規表現 | **使える** | **使えない** |
| `g` フラグ | **要る**（無いと行の最初だけ） | **不要**（常に全部） |
| 両側の長さ | 違ってよい | **そろえないとエラー** |
| 似ているコマンド | — | **`tr`** |

**`tr` とほぼ同じ働き**です
（[trによる文字の変換と削除](./trによる文字の変換と削除.md)）。

```bash
$ sed 'y/ab/AB/' t.txt                # sed でやる
$ tr ab AB < t.txt                    # tr でやる（結果は同じ）
```

**違いは「ファイル名を引数に取れるか」**です。
**`sed` は取れて、`tr` は取れません。**
**行を絞ってから変換したいときは `sed` の `y`**、
**まるごと変換するだけなら `tr`** が素直です。

```bash
$ sed '/^#/!y/ab/AB/' t.txt           # コメント行以外だけを変換する（sed でしかできない）
```

## 複数の処理をまとめる

**`-e` を並べると、複数のスクリプトを順番に適用します。**

```bash
$ sed -e 's/a/A/' -e 's/e/E/' sed.txt      # 2つの置換を順に適用する
ApplE
bAnana
chErry
#commEnt
ApplE pie
```

**`;` で区切っても同じ**です。

```bash
$ sed 's/a/A/; s/e/E/' sed.txt             # ; で区切る書き方
```

**処理の順番には意味があります。**
1 つ目の置換の結果に対して 2 つ目が適用されるので、
**`s/a/b/; s/b/c/` は `a` が `c` になります**（`b` を経由するため）。

**長くなるならスクリプトファイルにします。**

```bash
$ cat fix.sed                         # スクリプトを書いたファイル
s/old-host/new-host/g
/^#/d
$a # updated

$ sed -f fix.sed -i.bak nginx.conf    # ファイルからスクリプトを読んで適用する
```

**Ansible や構成管理から呼ぶときは、この形が読みやすい**です。

## 実務での使い方

| やりたいこと | コマンド |
|:--|:--|
| **設定値を書き換える** | `sed -i.bak 's/^Port 22/Port 2222/' /etc/ssh/sshd_config` |
| **コメントを外す** | `sed -i.bak 's/^#\(PermitRootLogin\)/\1/' sshd_config` |
| **コメントアウトする** | `sed -i.bak 's/^\(PasswordAuthentication\)/#\1/' sshd_config` |
| **末尾に追記する** | `sed -i.bak '$a AllowUsers deploy' sshd_config` |
| **コメントと空行を除いて見る** | `sed -e '/^#/d' -e '/^$/d' nginx.conf` |
| **CRLF を LF にする** | `sed -i 's/\r$//' file.txt` |
| **特定の範囲だけ抜き出す** | `sed -n '/^\[main\]/,/^\[/p' config.ini` |

**コメントを外す／付ける書き方は、実務でいちばんよく使います。**

```text
   s/^#\(PermitRootLogin\)/\1/
     │  └──────┬──────┘   └┬┘
     │      グループ1      グループ1の中身で置き換える
     └─ 行頭の # を消す（置換後に # を書かないので消える）
```

**補足 … `sed` で構造のあるファイルを触らないでください**

**YAML・JSON・XML を `sed` で書き換えるのは避けてください。**
インデントやクォートの構造を `sed` は理解しないため、壊れても気づけません。

| 形式 | 使うべきツール |
|:--|:--|
| **JSON** | **`jq`** |
| **YAML** | **`yq`** |
| **XML** | `xmlstarlet` |
| **INI / plain text** | **`sed` でよい** |
