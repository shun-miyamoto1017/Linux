## wcとは

**`wc` はファイルの行数・単語数・文字（バイト）数を数えるコマンド**です。
**word count の略**です。

```text
wc [オプション] [ファイル名]
```

**ファイル名を省略すると標準入力から読みます。** パイプの終端でよく使います。

### オプション無しの出力の順番

**オプションを付けないと 3 つの数がまとめて出ます。**
**順番は「行数 → 単語数 → 文字（バイト）数」で固定**です。

```bash
$ cat nlt.txt                         # 確認用のファイル（空行を含む5行）
one

two

three

$ wc nlt.txt                          # 3つの数をまとめて表示する
 5  3 16 nlt.txt
```

```text
 5  3 16 nlt.txt
 │  │ │  │
 │  │ │  └─ ファイル名
 │  │ └──── 文字（バイト）数
 │  └────── 単語数
 └───────── 行数
```

**この順番は試験で問われます。** 「行・単語・文字」の順、と覚えてください。

**補足 … 複数ファイルを渡すと `total` 行が付きます**

```bash
$ head -3 /etc/passwd > pw.txt         # 2つ目のファイルを用意する（3行）
$ wc nlt.txt pw.txt                   # 2つのファイルをまとめて数える
  5   3  16 nlt.txt
  3   3 117 pw.txt
  8   6 133 total
```

**最後の `total` はデータではなく合計行**です。
スクリプトで件数を使うときは、この行が混ざらないよう気をつけてください。

### よく使うオプション

| オプション | 意味 |
|:--|:--|
| **`-l`** | **行数**（lines） |
| **`-w`** | **単語数**（words） |
| **`-c`** | **バイト数**（characters ではなく **bytes**） |
| `-m` | **文字数**（multibyte を 1 文字と数える） |
| `-L` | いちばん長い行の**表示幅**（全角は 2 と数える） |

```bash
$ wc -l nlt.txt                       # 行数だけ
5 nlt.txt
$ wc -w nlt.txt                       # 単語数だけ
3 nlt.txt
$ wc -c nlt.txt                       # バイト数だけ
16 nlt.txt
$ wc -L nlt.txt                       # いちばん長い行の表示幅
5 nlt.txt
```

**`-L` は「文字数」ではなく「表示幅」**です。`-m` とは数え方が違います。

```bash
$ LC_ALL=en_US.UTF-8 wc -m ja.txt     # 文字数（あ・い・う・改行）
4 ja.txt
$ LC_ALL=en_US.UTF-8 wc -L ja.txt     # 表示幅（全角3文字 × 2桁）
6 ja.txt
```

**補足 … ファイル名を出したくないとき**

**リダイレクトやパイプで標準入力から渡すと、ファイル名が付きません。**
数字だけ欲しいときに便利です。

```bash
$ wc -l nlt.txt                       # ファイル名が付く
5 nlt.txt
$ wc -l < nlt.txt                     # リダイレクトなら数字だけ
5
$ cat nlt.txt | wc -l                 # パイプでも数字だけ
5
```

**`wc -l` の結果をそのまま変数に入れたいときは、リダイレクトかパイプ**を使ってください。

### -c と -m の違い

**`-c` はバイト数、`-m` は文字数**です。
**英数字だけなら一致しますが、日本語が入ると食い違います。**

```bash
$ cat ja.txt                          # ひらがな3文字＋改行
あいう
$ od -c ja.txt                        # バイト列を見る（UTF-8 は1文字3バイト）
0000000 343 201 202 343 201 204 343 201 206  \n
0000012
$ LC_ALL=en_US.UTF-8 wc -c ja.txt     # バイト数
10 ja.txt
$ LC_ALL=en_US.UTF-8 wc -m ja.txt     # 文字数
4 ja.txt
```

**`あいう` は UTF-8 で 3 バイト × 3 文字 ＝ 9 バイト、改行を足して 10 バイト**です。
文字数としては「あ・い・う・改行」で 4 になります。

**重要 … `-m` はロケールに依存します。**

```bash
$ LC_ALL=C wc -m ja.txt               # C ロケールでは1バイト＝1文字とみなす
10 ja.txt
```

**C ロケールだと `-m` は `-c` と同じ値**になりました（実測）。
**日本語の文字数を数えるときは、UTF-8 のロケールを明示**してください。

### 最後の行に改行が無いとき

**`wc -l` が数えているのは「改行文字の個数」**です。
**最後の行に改行が無いと、その行は数えられません。**

```bash
$ printf 'a\nb\nc\n' | wc -l          # 改行で終わっている
3
$ printf 'a\nb\nc' | wc -l            # 最後に改行が無い
2
```

**`c` の行が数えられていません。**
**ログの末尾が書きかけのときに 1 件ずれる**ので、覚えておいてください。

**「行らしきもの」を正しく数えたいときは `grep -c ''` を使います。**

```bash
$ printf 'a\nb\nc' | grep -c ''       # 改行が無くても3と数える
3
```

## nlとは

**`nl` はファイルの内容に行番号を付けて表示するコマンド**です。
**number lines の略**です。

```text
nl [オプション] [ファイル名]
```

```bash
$ nl nlt.txt                          # 行番号を付けて表示する
     1	one

     2	two

     3	three
```

**空行には番号が付いていません。** これが `nl` の既定の動きです。

### 空行に番号を付けるかどうか

**`-b`（body、本文の番号の付け方）で切り替えます。**

| 指定 | 意味 |
|:--|:--|
| **`-b t`** | **空行を除いた行だけに番号を付ける**（**既定**。t は text の意） |
| **`-b a`** | **空行も含めた全ての行に番号を付ける**（a は all の意） |
| `-b n` | 番号を付けない（n は none の意） |
| `-b p正規表現` | 正規表現に一致する行だけに番号を付ける |

```bash
$ nl -b a nlt.txt                     # 空行も含めて番号を付ける
     1	one
     2	
     3	two
     4	
     5	three
```

**`-b t`（既定）では「1 / 2 / 3」、`-b a` では「1 / 2 / 3 / 4 / 5」**になりました。
**ファイルの行数は 5 行**なので、**既定のままだと表示される番号と実際の行番号がずれます**。

**設定ファイルの「何行目」を数えるときは、必ず `-b a` を付けてください。**

### cat との対応

**`cat` にも行番号を付けるオプションがあり、`nl` と番号の付け方が対応します。**

| やりたいこと | **`nl`** | **`cat`** |
|:--|:--|:--|
| **空行も含めて全行に番号** | **`nl -b a`** | **`cat -n`** |
| **空行を除いた行に番号** | **`nl -b t`**（既定） | **`cat -b`** |

```bash
$ cat -n nlt.txt                      # nl -b a と同じ番号の付き方
     1	one
     2	
     3	two
     4	
     5	three
$ cat -b nlt.txt                      # nl -b t と同じ番号の付き方
     1	one

     2	two

     3	three
```

**「同じコマンド」ではありません。** 出力が完全に一致するわけではなく、
**番号を付けない行の扱いが違います。**

| | **`nl -b t`** | **`cat -b`** |
|:--|:--|:--|
| 番号を付けない行 | **桁幅ぶんの半角スペースで埋める** | **完全な空行** |
| 論理ページ区切り（`\:\:\:`） | **区切りとして解釈して食べる** | **ただの行として番号を付ける** |

**手順書に貼るなら `cat -n` / `cat -b` のほうが素直**です。
`nl` は書式を細かく指定したいときに使います。

**覚え方** … **`cat -n` の `n` は number（全部）**、
**`cat -b` の `b` は body（中身のある行だけ）**です。

```text
   全部に番号   …  nl -b a   ↔  cat -n
   中身だけ     …  nl -b t   ↔  cat -b
```

**`num` というコマンドは存在しません。** 試験では誤答として出ます。

### nl のそのほかのオプション

| オプション | 意味 |
|:--|:--|
| `-w 桁数` | 行番号の桁数（既定は 6） |
| `-n ln` / `-n rn` / `-n rz` | 左詰め／右詰め／ゼロ埋め |
| `-s 文字` | 行番号と本文の間の区切り（既定はタブ） |
| `-v 開始番号` | 何番から始めるか |
| `-i 増分` | いくつずつ増やすか |

```bash
$ nl -b a -n rz -w 3 -s ': ' nlt.txt  # 3桁ゼロ埋め、区切りを「: 」にする
001: one
002: 
003: two
004: 
005: three
```

## 実務での組み合わせ

| やりたいこと | 書き方 |
|:--|:--|
| **エラーの件数を数える** | `grep -c ERROR app.log` |
| **ユニークなアクセス元の数を数える** | `cut -d ' ' -f 1 access.log \| sort -u \| wc -l` |
| **ディレクトリ内のファイル数を数える** | `ls -1 \| wc -l` |
| **設定ファイルの実質的な行数** | `grep -v -e '^#' -e '^$' httpd.conf \| wc -l` |
| **行番号付きで設定ファイルを見る** | `nl -b a httpd.conf \| less` |
| **長すぎる行を探す** | `awk 'length($0) > 200 {print FILENAME": "NR}' *.conf` |

**補足 … `grep -c` と `wc -l` の違い**

**`grep -c` は「一致した行の数」**、**`wc -l` は「流れてきた行の数」**です。
**一致した行を数えるだけなら `grep -c` のほうが速く、パイプも 1 つ減ります。**

```bash
$ grep -c ERROR app.log               # こちらが素直
$ grep ERROR app.log | wc -l          # 同じ結果だが遠回り
```

ただし **`grep -c` は「1 行に何回出たか」は数えません**。
出現回数を数えたいときは `grep -o` と `wc -l` の組み合わせになります。

```bash
$ printf 'aaa\n' | grep -c a          # 「a を含む行」の数 → 1
1
$ printf 'aaa\n' | grep -o a | wc -l  # 「a の出現回数」 → 3
3
```
