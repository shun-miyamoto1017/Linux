## 検証で見つかった不具合

**検証環境（rpm 4.18.2 / dnf 4.14.0 / createrepo_c 0.17.3）で、
実際にローカルリポジトリを作り、署名あり・署名なし・依存不足・依存OK の各状態を再現して確認しました。**

| # | 重大度 | 不具合 | どうなるか |
|:--|:--|:--|:--|
| **1** | **重大** | **署名が入っていない RPM を素通りさせていた** | **出所不明の RPM が「署名確認 OK」として通る** |
| 2 | 中 | 日本語が `\xe8\xa6\x81...` に化けていた | 画面が読めない |
| 3 | 中 | `grep -P` が使えない環境で不足依存を取りこぼす | **依存不足なのに「依存OK」と誤判定しうる** |
| 4 | 中 | `best` の値をログに残していない | `best=0` のとき画面の読み方が変わるのに記録がない |
| 5 | 中 | `(not installed: 要調査)` が多発する | 自分で調べ直す手間が増える |
| 6 | 低 | `grep -i 'multilib'` が画面を汚す | 関係ない行が出る |
| 7 | 低 | `.repo` ファイル名がリポジトリIDと同じ前提 | 名前が違うと「ファイルがありません」で止まる |
| 8 | 低 | `rpm -q --whatprovides` の `2>/dev/null` が効いていない | 偶然動いているだけ |
| 9 | 低 | 判定の順番に意味があるのにコメントがない | あとで並べ替えると壊れる |

### 1【重大】署名が入っていない RPM を素通りさせていた

**元版の判定はこれでした。**

```bash
rpm -K "$REPO_DIR"/*.rpm > "$RDIR/signature.txt" 2>&1
if grep -Eq 'NOT OK|MISSING KEYS' "$RDIR/signature.txt"; then
  fail "署名NGの RPM があります"
fi
log "署名確認: OK"
```

**`rpm -K` の 5 パターンを実測しました。**

| RPM の状態 | `rpm -K` の出力 | 終了ステータス | 元版で検出できたか |
|:--|:--|:--|:--|
| 署名あり・鍵登録済み・壊れていない | `digests signatures OK` | 0 | — （正常） |
| 署名あり・鍵が未登録 | `digests SIGNATURES NOT OK` | 1 | ✅ できた |
| 署名あり・壊れている | `DIGESTS SIGNATURES NOT OK` | 1 | ✅ できた |
| **署名が入っていない・壊れていない** | **`digests OK`** | **0** | ❌ **できない** |
| 署名が入っていない・壊れている | `DIGESTS NOT OK` | 1 | ✅ できた |

**4 行目です。署名が入っていない RPM は `digests OK` で終了ステータス 0 を返します。**
`NOT OK` も `MISSING KEYS` も出ないので、**元版は「署名確認: OK」と表示して先に進みます。**

実測です。署名なしの RPM を 1 本混ぜました。

```text
/opt/localrepo/appx-1.0-1.noarch.rpm: digests signatures OK
/opt/localrepo/libbar-1.1-1.noarch.rpm: digests signatures OK
/opt/localrepo/libbaz-1.1-1.noarch.rpm: digests OK              ← 署名が無い
```

```text
$ rpm -K /opt/localrepo/*.rpm | grep -E 'NOT OK|MISSING'
（何も表示されない）
```

> **なぜ `digests OK` になるのか。**
> `rpm -K` は「**ダイジェスト（壊れていないか）**」と「**署名（誰が作ったか）**」を見ます。
> **署名が入っていない RPM には検証する署名が存在しない**ので、ダイジェストだけを見て OK を返します。
> **「確認しなかった」が「問題なし」として出てくる**のが、この落とし穴の正体です。

**修正**: `rpm -K` とは別に、**署名が入っているかを 1 本ずつ確認**します。

```bash
# 署名そのものが入っているかを1本ずつ確認する
for f in "$REPO_DIR"/*.rpm; do
  sig=$(rpm -qpi "$f" 2>/dev/null | sed -n 's/^Signature *: *//p')
  printf '%s\t%s\n' "$(basename "$f")" "${sig:-(取得失敗)}" >> "$RDIR/signature_detail.txt"
  case "$sig" in
    ""|"(none)") basename "$f" >> "$RDIR/unsigned.txt" ;;
  esac
done
```

修正版で同じ状態を実行した結果です。

```text
[12:55:13] ❌ 署名が入っていない RPM があります（1 件）
   libbaz-1.1-1.noarch.rpm
[ERROR] 署名なしの RPM は出所を保証できません。Red Hat カスタマーポータルから取り直してください
```

**終了ステータス 2 で止まるようになりました。**

### 2 日本語が化けていた

元版は先頭で `export LC_ALL=C` しています。**メッセージを英語に固定して解析を安定させるため**で、これ自体は正しい判断です。
**ところが `column` コマンドも `LC_ALL=C` のまま動くので、日本語を認識できず文字化けします。**

実測です。

```text
missing_capability  hint_package
libbaz              (not installed: \xe8\xa6\x81\xe8\xaa\xbf\xe6\x9f\xbb)
```

**`\xe8\xa6\x81...` は「要調査」の UTF-8 バイト列**です。

**修正**: **表を出すときだけロケールを戻す**関数を作りました。

```bash
ORIG_LANG="${LANG:-C.UTF-8}"
# 表を出すときだけロケールを戻す（LC_ALL=C のままだと日本語が \xNN に化ける）
print_table() { LC_ALL="$ORIG_LANG" column -t -s $'\t' "$1"; }
```

**あわせて、ヒント文字列も ASCII に変えました**（`(server does not have it: needs lookup)`）。
**ロケールが何であっても読める**ようにするためです。

### 3 grep -P が使えないと黙って取りこぼす

元版の dnf 側の抽出はこうでした。

```bash
{
  grep -oP 'nothing provides \K.+?(?= needed by)' "$RDIR/dryrun.txt"
  grep -oP 'requires \K.+?(?=, but none of the providers can be installed)' "$RDIR/dryrun.txt"
} 2>/dev/null | sort -u > "$RDIR/missing.txt"
```

- **`grep -P` は PCRE（Perl 互換正規表現）**を使うオプションです。`\K` や `(?=...)` はこれが無いと使えません
- **`2>/dev/null` でエラーを捨てている**ので、`-P` が使えない環境では**両方とも黙って失敗**します
- すると `missing.txt` が空になり、**依存不足なのに「依存OK」や「更新対象なし」と判定されうる**

**RHEL の `grep` は通常 `-P` に対応しています**（検証環境でも使えました）が、
**「黙って間違った結果を出す」のがいちばん危ない**ので、先に確認するようにしました。

**修正**:

```bash
# dnf 側の不足依存の抽出に grep -P を使う。使えない環境だと黙って取りこぼすので先に確認する。
if [[ $PKG == dnf ]]; then
  echo x | grep -qoP 'x' 2>/dev/null || fail "grep -P が使えません（この環境では不足依存を抽出できません）"
fi
```

### 4 best の値をログに残していない

**`best` の値で、依存不足のときの画面がまったく変わります。**検証環境で両方作って確認しました。

| `best` | 表示 | 終了ステータス |
|:--|:--|:--|
| **`True`** | **`Error:` ＋ `Problem:` で停止** | 1 |
| **`False`** | **`Skipping packages with broken dependencies:` → `Nothing to do.` → `Complete!`** | **0** |

`best=False` のときの実測です。

```text
Skipping packages with broken dependencies:
 libbar           noarch           1.1-1              localrepo           6.0 k

Transaction Summary
Skip  1 Package

Nothing to do.
Complete!
```

**あとでログを見返したときに、どちらの環境だったか分からないと読み解けません。**

**修正**: ラウンドの最初にログへ出します。

```bash
# best の値を残す。これが True か False かで、依存不足のときの画面が変わる。
BEST_VAL=$("$PKG" config-manager --dump 2>/dev/null | sed -n 's/^best *= *//p' | head -n1)
[[ -n "$BEST_VAL" ]] && log "best の設定値: $BEST_VAL（1=True なら依存不足で Error 停止、0=False なら Skip して Nothing to do）"
```

### 5 (not installed: 要調査) が多発する

元版は、足りないものの名前をそのまま `rpm -q --whatprovides` に渡していました。
**`libcrypto.so.3(OPENSSL_3.0.9)(64bit)` のようにカッコ付きのバージョン記号が付いていると当たりません。**
古い版はその記号を持っていないからです。

**手順書には「記号を外して調べ直す」と書いてあったのに、スクリプトはやっていませんでした。**

実測で再現しました（`libtest` というテスト用パッケージを作成）。

```text
$ rpm -q --whatprovides 'libtest.so.3(TESTVER_1.0)(64bit)'
no package provides libtest.so.3(TESTVER_1.0)(64bit)        ← 当たらない

$ rpm -q --whatprovides 'libtest.so.3()(64bit)'
libtest-1.0-1.noarch                                        ← 当たった
```

**修正**: 1 回目で当たらなければ、**記号を外して再検索**します。

```bash
# 例: libcrypto.so.3(OPENSSL_3.0.9)(64bit) → libcrypto.so.3()(64bit)
stripped=$(sed -E 's/\(([A-Za-z0-9_.]+)\)\(/()(/' <<< "$name")
```

関数単体で動かした実測です。

```text
libtest.so.3(TESTVER_1.0)(64bit)         -> libtest.noarch (記号を外して特定)
libtest.so.3()(64bit)                    -> libtest.noarch
libbar >= 1.1                            -> libbar.noarch
libnothing.so.9()(64bit)                 -> (server does not have it: needs lookup)
```

### 6〜9 そのほか

| # | 元版 | 修正版 |
|:--|:--|:--|
| 6 | `grep -i 'multilib' ... && log "⚠️ ..."` → **マッチした行が画面に出てしまう** | **`grep -qi`** にして、判定だけに使う |
| 7 | `[[ -f "/etc/yum.repos.d/${REPO_ID}.repo" ]]` → **ファイル名がIDと同じ前提** | **`grep -rqs "^\[${REPO_ID}\]" /etc/yum.repos.d/`** で中身から探す |
| 8 | `rpm -q --whatprovides "$name" 2>/dev/null` → **「no package provides」は stdout に出るので捨てられていない** | **出力の中身も見て判定**（`[[ $hint != *"no package provides"* ]]`） |
| 9 | 判定の順番にコメントがない | **「順番に意味がある」ことをコメントで明記** |

> **#9 がなぜ大事か。**
> **`best=False` のときは、依存不足でも最後に `Nothing to do.` が出ます。**
> もし「`Nothing to do.` か？」を先に判定すると、**依存不足を「更新対象なし」と誤判定**します。
> **だから「不足依存があるか」を必ず先に見ます。**並べ替えてはいけません。

## 1ブロックずつの解説

### 先頭の宣言

```bash
#!/usr/bin/env bash
set -uo pipefail
export LC_ALL=C
ORIG_LANG="${LANG:-C.UTF-8}"
```

| 書き方 | 意味 |
|:--|:--|
| `#!/usr/bin/env bash` | **bash で実行する**という宣言。`env` 経由にすると、bash の場所が違う OS でも動く |
| **`set -u`** | **未定義の変数を使ったらエラーにする。**変数名のタイプミスを拾える |
| **`set -o pipefail`** | **パイプの途中で失敗したら、全体を失敗にする**（既定では最後のコマンドの結果だけを見る） |
| **`set -e` は付けていない** | **`grep` が「見つからなかった」ときの終了ステータス 1 で止まってしまうため。**このスクリプトは `grep` の結果を判定に使うので、わざと付けていません |
| `export LC_ALL=C` | **`dnf` / `yum` のメッセージを英語に固定する。**解析を安定させるため |
| `ORIG_LANG=...` | **元のロケールを覚えておく**（表を出すときに戻すため） |

### 変数と関数

```bash
REPO_DIR="${REPO_DIR:-/opt/localrepo}"
REPO_ID="${REPO_ID:-localrepo}"
LOG_DIR="${LOG_DIR:-/var/tmp/depcheck_$(date +%Y%m%d)}"
TARGET="${1:-}"

log()  { echo "[$(date '+%H:%M:%S')] $*"; }
fail() { echo "[ERROR] $*" >&2; exit 2; }
print_table() { LC_ALL="$ORIG_LANG" column -t -s $'\t' "$1"; }
```

| 書き方 | 意味 |
|:--|:--|
| **`${REPO_DIR:-/opt/localrepo}`** | **環境変数 `REPO_DIR` が設定されていればそれを使い、無ければ `/opt/localrepo` を使う。**これで、置き場所を変えたいときに**スクリプトを書き換えずに済みます** |
| **`${1:-}`** | **1 番目の引数。無ければ空文字。**`set -u` があるので `${1}` だけだとエラーになります |
| `log()` | **時刻付きでメッセージを出す**（証跡として時刻が残る） |
| `fail()` | **メッセージを標準エラーに出して、終了ステータス 2 で終わる** |
| `print_table()` | **表を出す。ロケールだけ戻す**（文字化け対策） |

### 前提チェック

```bash
[[ $EUID -eq 0 ]] || fail "root で実行してください"
[[ -d "$REPO_DIR" ]] || fail "REPO_DIR が存在しません: $REPO_DIR"
ls "$REPO_DIR"/*.rpm >/dev/null 2>&1 || fail "RPM がありません: $REPO_DIR"
if ! grep -rqs "^\[${REPO_ID}\]" /etc/yum.repos.d/; then
  fail "リポジトリID [${REPO_ID}] の .repo が /etc/yum.repos.d/ に見つかりません"
fi
```

| 書き方 | 意味 |
|:--|:--|
| **`$EUID`** | **実行中の実効ユーザーID。root なら 0** |
| **`A \|\| B`** | **A が失敗したら B を実行する。**「チェックして、駄目なら止める」の定型 |
| `[[ -d ... ]]` | ディレクトリとして存在するか |
| **`grep -rqs "^\[localrepo\]"`** | **`.repo` ファイルの中身から `[localrepo]` の行を探す。**`-r` は再帰、`-q` は表示しない、`-s` はエラーを出さない |

💡 **`.repo` のファイル名はリポジトリIDと同じでなくても動きます。**だから中身で探しています。

### OS 判定

```bash
if command -v dnf >/dev/null 2>&1; then
  PKG=dnf; SUBCMD=upgrade; CREATEREPO=createrepo_c
else
  PKG=yum; SUBCMD=update;  CREATEREPO=createrepo
fi
```

**`dnf` コマンドがあるかどうかで、RHEL 8 以降か RHEL 7 かを判定しています。**

| 変数 | RHEL 8 以降 | RHEL 7 |
|:--|:--|:--|
| `PKG` | `dnf` | `yum` |
| `SUBCMD` | **`upgrade`** | **`update`** |
| `CREATEREPO` | **`createrepo_c`** | **`createrepo`** |

💡 **`command -v` は「そのコマンドがあるか」を調べる書き方**です。`which` より移植性が高いです。
⚠️ **RHEL 8 以降では `yum` も使えますが、中身は `dnf` です。**
　この判定は `dnf` があるかを見ているので、RHEL 8 以降では必ず `dnf` 側になります。

### ラウンド用ディレクトリ

```bash
mkdir -p "$LOG_DIR"
PREV_RDIR=$(ls -d "$LOG_DIR"/round[0-9]* 2>/dev/null | sort | tail -n1 || true)
ROUND_NO=$(( $(ls -d "$LOG_DIR"/round[0-9]* 2>/dev/null | wc -l) + 1 ))
RDIR="$LOG_DIR/round$(printf '%02d' "$ROUND_NO")"
mkdir -p "$RDIR"
```

**`round01` / `round02` … というフォルダを自動で作り、ラウンドごとに証跡を分けます。**

| 書き方 | 意味 |
|:--|:--|
| `ls -d .../round[0-9]*` | **すでにあるラウンドのフォルダを列挙する** |
| `\| sort \| tail -n1` | **いちばん新しいものを 1 つ取る**（前ラウンドのフォルダ） |
| `\|\| true` | **1 つも無いときに失敗で止まらないようにする** |
| `wc -l` + 1 | **今回のラウンド番号を数える** |
| **`printf '%02d'`** | **2 桁にそろえる**（`1` → `01`）。これで `sort` の並び順が崩れません |

### 署名確認

```bash
rpm -K "$REPO_DIR"/*.rpm > "$RDIR/signature.txt" 2>&1
if grep -Eqi 'NOT OK|MISSING KEYS' "$RDIR/signature.txt"; then
  grep -Ei 'NOT OK|MISSING KEYS' "$RDIR/signature.txt"
  fail "壊れている、または鍵の合わない RPM があります..."
fi

: > "$RDIR/signature_detail.txt"
: > "$RDIR/unsigned.txt"
for f in "$REPO_DIR"/*.rpm; do
  sig=$(rpm -qpi "$f" 2>/dev/null | sed -n 's/^Signature *: *//p')
  printf '%s\t%s\n' "$(basename "$f")" "${sig:-(取得失敗)}" >> "$RDIR/signature_detail.txt"
  case "$sig" in
    ""|"(none)") basename "$f" >> "$RDIR/unsigned.txt" ;;
  esac
done
if [[ -s "$RDIR/unsigned.txt" ]]; then
  ...
  fail "署名なしの RPM は出所を保証できません..."
fi
```

**2 段構えになっています。ここがこのスクリプトでいちばん大事な部分です。**

| 段 | 何を見ているか | これだけでは足りない理由 |
|:--|:--|:--|
| **1 段目**（`rpm -K`） | **壊れていないか／鍵が合っているか** | **署名が入っていない RPM を検出できない** |
| **2 段目**（`Signature` 行） | **署名そのものが入っているか** | 壊れているかは分からない |

| 書き方 | 意味 |
|:--|:--|
| **`: > ファイル`** | **ファイルを空にする**（`:` は「何もしない」コマンド）。前回の内容が残らないようにする |
| **`sed -n 's/^Signature *: *//p'`** | **`Signature   : ...` の行から、`: ` の後ろだけを取り出す。**`-n` と `p` の組み合わせで「マッチした行だけ出す」 |
| **`${sig:-(取得失敗)}`** | `sig` が空なら `(取得失敗)` と表示する |
| **`case "$sig" in ""\|"(none)")`** | **空、または `(none)` なら署名なしと判定** |
| **`[[ -s ファイル ]]`** | **ファイルが存在して、中身が空でない** |

### 目次更新とキャッシュ削除

```bash
"$CREATEREPO" --update "$REPO_DIR" > "$RDIR/createrepo.log" 2>&1 \
  || fail "$CREATEREPO に失敗しました（$RDIR/createrepo.log）"
"$PKG" clean all > /dev/null 2>&1
```

**この 2 つが、このスクリプトの存在意義です。**手動でやると忘れやすいところを、毎回必ず実行します。

| 書き方 | 意味 |
|:--|:--|
| `> ファイル 2>&1` | **標準出力と標準エラーの両方をファイルに入れる**（`2>&1` が「標準エラーも標準出力と同じところへ」） |
| `\|\| fail ...` | **失敗したら止める** |
| `> /dev/null 2>&1` | **出力を全部捨てる**（`clean all` の出力は読まなくてよいため） |

### ドライラン

```bash
"$PKG" --disablerepo='*' --enablerepo="$REPO_ID" "$SUBCMD" --assumeno ${TARGET:+"$TARGET"} \
  > "$RDIR/dryrun.txt" 2>&1
```

| 書き方 | 意味 |
|:--|:--|
| **`--disablerepo='*' --enablerepo=ID`** | **全リポジトリを無効化してから、ローカルリポジトリだけ有効化**。オフラインサーバで外を見に行かせないため |
| **`--assumeno`** | **確認プロンプトに自動で No と答える。**依存解決まではやるので、下見に使える |
| **`${TARGET:+"$TARGET"}`** | **`TARGET` が空でなければそれを渡し、空なら何も渡さない。**`${TARGET:-}` との違いは `+` と `-`。これで「引数なしなら全パッケージ」が実現します |

### 不足依存の抽出

```bash
if [[ $PKG == yum ]]; then
  grep -E '^[[:space:]]+Requires:' "$RDIR/dryrun.txt" \
    | sed -E 's/^[[:space:]]+Requires:[[:space:]]*//' | sort -u > "$RDIR/missing.txt"
else
  {
    grep -oP 'nothing provides \K.+?(?= needed by)' "$RDIR/dryrun.txt"
    grep -oP 'requires \K.+?(?=, but none of the providers can be installed)' "$RDIR/dryrun.txt"
  } 2>/dev/null | sort -u > "$RDIR/missing.txt"
fi
```

**`yum` と `dnf` でエラーの形が違うので、別々に書いています。**

**yum（RHEL 7）の形**

```text
Error: Package: openssh-server-7.4p1-23.el7_9.x86_64 (localrepo)
           Requires: openssl-libs >= 1:1.0.2k-26
```

`Requires:` の行を拾って、`Requires:` の文字を取り除いています。

**dnf（RHEL 8 以降）の形**

```text
  - nothing provides libbaz needed by libbar-1.1-1.noarch
```

| 書き方 | 意味 |
|:--|:--|
| **`grep -o`** | **マッチした部分だけを出す**（行全体ではなく） |
| **`grep -P`** | **PCRE（Perl 互換正規表現）を使う** |
| **`\K`** | **ここまでのマッチを「無かったこと」にする。**`nothing provides ` の後ろから出力が始まる |
| **`.+?`** | **できるだけ短くマッチする**（`?` が「最短一致」） |
| **`(?= needed by)`** | **「この後ろに ` needed by` が続く」という条件だけ見て、それ自体はマッチに含めない**（先読み） |
| `{ A; B; } \| sort -u` | **2 つのコマンドの出力をまとめてソートし、重複を消す** |

💡 **つまり `nothing provides libbaz needed by ...` から `libbaz` だけを取り出しています。**

### ヒントの推測

```bash
whatprovides_hint() {
  local cap="$1" name hint
  name=$(awk '{print $1}' <<< "$cap")
  if hint=$(rpm -q --whatprovides "$name" --qf '%{NAME}.%{ARCH}\n' 2>/dev/null) \
       && [[ $hint != *"no package provides"* ]]; then
    sort -u <<< "$hint" | paste -sd, -; return
  fi
  local stripped
  stripped=$(sed -E 's/\(([A-Za-z0-9_.]+)\)\(/()(/' <<< "$name")
  if [[ $stripped != "$name" ]] \
     && hint=$(rpm -q --whatprovides "$stripped" --qf '%{NAME}.%{ARCH}\n' 2>/dev/null) \
     && [[ $hint != *"no package provides"* ]]; then
    echo "$(sort -u <<< "$hint" | paste -sd, -) (記号を外して特定)"; return
  fi
  echo "(server does not have it: needs lookup)"
}
```

**「足りないもの」から「取ってくるパッケージ名」を推測します。**
**サーバに入っている古い版が手がかり**です。

| 書き方 | 意味 |
|:--|:--|
| **`local`** | **関数の中だけで使う変数にする。**付けないと外の変数を壊すことがある |
| **`<<< "$cap"`** | **文字列をそのままコマンドの標準入力に渡す**（here-string） |
| **`awk '{print $1}'`** | **1 番目の単語だけ取る。**`openssl-libs >= 1:3.0.7` → `openssl-libs` |
| **`rpm -q --whatprovides`** | **その能力を提供しているパッケージを、サーバに入っているものから探す** |
| **`--qf '%{NAME}.%{ARCH}\n'`** | **表示の形を指定**（`openssl-libs.x86_64` の形にする） |
| **`paste -sd, -`** | **複数行をカンマ区切りの 1 行にまとめる** |
| **`sed -E 's/\(([A-Za-z0-9_.]+)\)\(/()(/'`** | **`(OPENSSL_3.0.9)(` を `()(` に置き換える**＝カッコ付きの記号を外す |

**3 段構えで調べています。**

```text
  ① そのまま調べる          libcrypto.so.3(OPENSSL_3.0.9)(64bit)  → 当たらないことが多い
  ② 記号を外して調べる       libcrypto.so.3()(64bit)               → ここで当たる
  ③ それでも駄目なら「要調査」 → 付録A の手順で人が調べる
```

### 判定

```bash
if [[ -s "$RDIR/missing.txt" ]]; then        # ① 不足依存があるか
  ... exit 1
fi
if grep -Eq 'No packages marked for update|Nothing to do' ...; then   # ② 更新対象なしか
  ... exit 3
fi
if grep -Eq '^Error|^ *Problem|Protected multilib' ...; then          # ③ 解析できないエラーか
  ... exit 2
fi
if grep -Eq 'Exiting on user command|Operation aborted' ...; then     # ④ 正常終了したか
  ... exit 0
fi
```

> **⚠️ この順番には意味があります。並べ替えてはいけません。**
> **`best=False` のときは、依存不足でも最後に `Nothing to do.` が出ます。**
> ①と②を入れ替えると、**依存不足を「更新対象なし」と誤判定**します。

**終了ステータスの意味**

| 終了ステータス | 意味 | 次にやること |
|:--|:--|:--|
| **0** | **依存OK** | 本番適用へ進む |
| **1** | **依存不足あり** | `missing_hint.tsv` を見て RPM を追加 → 再実行 |
| **2** | **その他のエラー**（署名NG / createrepo 失敗 / 解析できないエラー） | `dryrun.txt` を読む／相談 |
| **3** | **更新対象なし** | RPM の取り違え・適用済みでないか確認 |

💡 **終了ステータスを分けているので、ジョブから呼んで分岐させることもできます。**

```bash
$ sudo -E /root/bin/check_deps.sh; rc=$?    # 終了ステータスを受け取る
$ case "$rc" in                             # 終了ステータスで分岐する
    0) echo "適用できる" ;;
    1) echo "RPM が足りない" ;;
    *) echo "要確認（rc=$rc）" ;;
  esac
```

### 最後の確認（依存OK のとき）

```bash
for f in "$REPO_DIR"/*.rpm; do
  rpm -qp --qf '%{NAME}.%{ARCH}\n' "$f" 2>/dev/null
done | sort -u | while IFS= read -r na; do
  rpm -q "$na" >/dev/null 2>&1 || echo "$na"
done > "$RDIR/not_installed.txt"
```

**「リポジトリにあるが、サーバには入っていないパッケージ」を洗い出します。**

**なぜ大事か。** `upgrade` は**すでに入っているものを新しくするコマンド**です。
**入っていないパッケージは、依存として必要にならない限り適用されません。**
**「99 本持ち込んだのに 96 本しか更新されない」のは、多くの場合これが理由**です。

| 書き方 | 意味 |
|:--|:--|
| **`rpm -qp`** | **RPM ファイルに対して問い合わせる**（`-p` が「ファイルに対して」） |
| **`rpm -q`**（`-p` なし） | **サーバに入っているものに対して問い合わせる** |
| **`while IFS= read -r na`** | **1 行ずつ読む定型**。`IFS=` で前後の空白を保ち、`-r` でバックスラッシュをそのまま扱う |

## 自分で検証する方法

**本番に当てる前に、検証環境で動作を確かめてください。**
検証環境で実際にやった手順です。**RHEL でも同じ流れで試せます。**

### 1 テスト用のリポジトリを作る

```bash
$ sudo mkdir -p /opt/localrepo                              # 置き場所を作る
$ sudo cp <適当なRPMを数本> /opt/localrepo/                  # RPM を置く
$ sudo createrepo_c /opt/localrepo                          # 目次を作る
$ sudo tee /etc/yum.repos.d/localrepo.repo > /dev/null <<'EOF'   # .repo を作る
[localrepo]
name=Local Repo
baseurl=file:///opt/localrepo
enabled=1
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-redhat-release
EOF
$ dnf --repo=localrepo repolist -v | grep -E 'Repo-id|Repo-pkgs'   # 認識されたか
```

### 2 4 つのパターンを作って動作を確かめる

| 試すこと | 作り方 | 期待する結果 |
|:--|:--|:--|
| **署名なしを検出するか** | 自分でビルドした（署名していない）RPM を 1 本混ぜる | **終了ステータス 2 で止まり、ファイル名が表示される** |
| **依存不足を検出するか** | 依存先の RPM を 1 本わざと置かない | **終了ステータス 1。`missing_hint.tsv` に出る** |
| **依存OK を検出するか** | 足りない RPM を足す | **終了ステータス 0。`Transaction Summary` が出る** |
| **ラウンドが進むか** | 同じ `LOG_DIR` で 2 回実行する | **`round01` / `round02` ができ、`前ラウンドから追加された RPM: N 件` が出る** |

```bash
$ export LOG_DIR=/var/tmp/depcheck_test          # テスト用の保存先
$ sudo -E /root/bin/check_deps.sh ; echo "exit=$?"   # 実行して終了ステータスを見る
```

### 3 best の両方で試す

```bash
$ sudo cp /etc/dnf/dnf.conf /etc/dnf/dnf.conf.bak          # 元の設定を退避する
$ sudo sed -i 's/^best=True/best=False/' /etc/dnf/dnf.conf # False にして試す
$ sudo -E /root/bin/check_deps.sh ; echo "exit=$?"         # 依存不足でも 1 になるか
$ sudo cp /etc/dnf/dnf.conf.bak /etc/dnf/dnf.conf          # 元に戻す
```

**依存不足の状態で `best=False` にしても、終了ステータスが 1 のままになることを確認してください。**
**3 になったら、判定の順番が壊れています。**

### 4 構文チェックだけでもやる

```bash
$ bash -n /root/bin/check_deps.sh && echo "構文チェック OK"   # 実行せずに文法だけ見る
```

💡 **`shellcheck` が使えるなら、さらに細かい指摘が得られます**（`shellcheck -S warning check_deps.sh`）。
　検証環境には入っていなかったため未実施です。

## 残っている制約

**修正版でも、次は未解決です。**本番で使う前に承知しておいてください。

| 制約 | 内容 |
|:--|:--|
| **RHEL 7 での動作は未検証** | **検証環境は rpm 4.18 / dnf 4.14 のみ。**`yum` 側の分岐（`Requires:` の抽出、`Exiting on user command` の判定）は**実機で確認していません** |
| **`rpm -K` の文字列は rpm のバージョン依存** | RHEL 7（rpm 4.11）は `rsa sha1 (md5) pgp md5 OK` のような別の形になります。**`NOT OK` を拾う部分は動くはず**ですが未検証です |
| **RHEL 9.7 以降の post-quantum 署名は見ていない** | RPMv6 署名の検証には `/usr/lib/pqrpm/bin/rpmkeys -Kv` が必要です。**このスクリプトは従来の `rpm -K` しか使いません** |
| **Key ID が Red Hat のものかは判定していない** | `signature_detail.txt` に Key ID を出すだけです。**Red Hat 公式の一覧との照合は人がやってください** |
| **Modularity には対応していない** | `modules.yaml` の取り込みはしません。モジュール対象パッケージがあると `filtered out by modular filtering` になります |
| **`shellcheck` を通していない** | 検証環境に無かったため未実施です |
