## ファイルの種類を調べる

「`file`」コマンドでファイルの種類を表示できます。

拡張子ではなく、**ファイルの先頭にある特徴的なバイト列（マジックナンバー）**を見て判断します。
Linux では拡張子に意味がないため、中身を確かめる唯一の手段になります。

```bash
$ file original                     # ファイルの種類を判定する
original: ASCII text

$ file /bin/ls                      # 実行ファイルを判定する
/bin/ls: ELF 64-bit LSB pie executable, x86-64, dynamically linked

$ file /etc                         # ディレクトリも判定できる
/etc: directory

$ file backup.xz                    # 圧縮ファイルの形式がわかる
backup.xz: XZ compressed data
```

### 主なオプション

| オプション | 意味 |
|:--|:--|
| `-b` | ファイル名を表示せず、種類だけを出す |
| `-i` | MIME タイプで表示する |
| `-f リスト` | ファイル名を並べたリストから読み込む |
| `-z` | 圧縮ファイルの**中身**を調べる |
| `-L` | シンボリックリンクの**リンク先**を調べる |

```bash
$ file -b original                  # 種類だけを表示する
ASCII text

$ file -i original                  # MIME タイプで表示する
original: text/plain; charset=us-ascii

$ file -z backup.tar.gz             # 圧縮の中身まで判定する
backup.tar.gz: POSIX tar archive (GNU) (gzip compressed data)
```

**補足 … 拡張子に騙されないための道具です**

`.txt` という名前でも中身が画像、ということがありえます。
アップロードされたファイルを扱うときは、拡張子ではなく `file` で判定します。

```bash
$ mv photo.jpg photo.txt            # 拡張子だけ変えてみる
$ file photo.txt                    # 中身は JPEG のままだと分かる
photo.txt: JPEG image data, JFIF standard 1.01
```

**補足 … 文字コードの調査にも使えます**

```bash
$ file -i data.csv                  # 文字コードを確認する
data.csv: text/plain; charset=utf-8

$ file script.sh                    # 改行コードも分かる
script.sh: Bourne-Again shell script, ASCII text executable, with CRLF line terminators
                                    # ↑ CRLF なら Windows 改行（動かない原因になる）
```

## 三つのタイムスタンプ

Linux のファイルは、**3 種類の時刻**を持っています。

| 名前 | 正式名 | 意味 | 例 |
|:--|:--|:--|:--|
| **atime** | access time | **最終アクセス時刻** | `cat` で読んだ |
| **mtime** | modify time | **最終変更時刻**（中身） | `vi` で編集して保存した |
| **ctime** | change time | **最終変更時刻**（inode データも） | `chmod` で権限を変えた |

**`ctime` は「create time（作成時刻）」ではありません。** ここが最も誤解される点です。
`ctime` は **inode（ファイルの管理情報）が変わった時刻**を指します。

```
ファイルの構成

  ┌─────────────┐
  │  inode      │ ← 権限・所有者・サイズ・リンク数・3つの時刻
  │  （管理情報）│    ここが変わると ctime が更新される
  └─────────────┘
        ↓
  ┌─────────────┐
  │  データ本体  │ ← ここが変わると mtime（と ctime）が更新される
  └─────────────┘    ここを読むと atime が更新される
```

**補足 … 作成時刻（birth time）は別にあります**

ext4 や XFS は作成時刻を持っていますが、**古いカーネルや `stat` では表示されません**。
表示されても `Birth: -` となることがあります。

```bash
$ stat original | grep Birth        # 作成時刻を確認する
 Birth: -                           # 記録されていない環境ではこうなる

$ stat --printf='%w\n' original    # 作成時刻を取得してみる（空なら未記録）
                                    # 新しい環境なら取得できることがある
```

## タイムスタンプを確認する

### stat コマンド

**ファイルの詳細情報を表示する `stat` コマンドでファイルのタイムスタンプを確認できます。**

```bash
$ stat original                     # ファイルの詳細情報を表示する
  File: `original'
  Size: 6
Device: fd00h/64768d
Access: (0664/-rw-rw-r--)  Uid: ( 1002/   staff)   Gid: ( 1003/   staff)
Context: unconfined_u:object_r:user_home_t:s0
Access: 2019-09-12 10:56:37.783285724 +0900    ← atime : 最終アクセス時刻
Modify: 2019-09-12 10:56:37.783285724 +0900    ← mtime : 最終変更時刻
Change: 2019-09-12 10:56:37.783285724 +0900    ← ctime : 最終変更時刻（inodeデータも）
 Birth: -
```

**読み方の注意** … `Access:` という行が **2 回**出てきます。

| 行 | 意味 |
|:--|:--|
| `Access: (0664/-rw-rw-r--)` | **パーミッション**（権限） |
| `Access: 2019-09-12 ...` | **atime**（最終アクセス時刻） |

日付が入っているほうが atime です。

### 主なオプション

| オプション | 意味 |
|:--|:--|
| `-c 書式` | 表示内容を書式で指定する |
| `-f` | ファイルではなくファイルシステムの情報を表示する |
| `-L` | シンボリックリンクのリンク先を対象にする |
| `-t` | 1 行にまとめて表示する |

```bash
$ stat -c '%n %y' original          # ファイル名と mtime だけ表示する
original 2019-09-12 10:56:37.783285724 +0900

$ stat -c '%A %U %G %s' original    # 権限・所有者・グループ・サイズ
-rw-rw-r-- staff staff 6
```

| 書式 | 意味 |
|:--|:--|
| `%n` | ファイル名 |
| `%s` | サイズ（バイト） |
| `%A` | 権限（記号表記） |
| `%a` | 権限（数値表記） |
| `%U` / `%G` | 所有者 / グループ |
| `%x` / `%y` / `%z` | atime / mtime / ctime |
| `%i` | inode 番号 |

### ls で確認する

`ls -l` が表示するのは **mtime** です。オプションで切り替えられます。

```bash
$ ls -l original                    # 既定は mtime（最終変更時刻）
-rw-rw-r--. 1 staff staff 6 Sep 12 10:56 original

$ ls -lu original                   # -u で atime（最終アクセス時刻）
-rw-rw-r--. 1 staff staff 6 Sep 12 10:57 original

$ ls -lc original                   # -c で ctime
-rw-rw-r--. 1 staff staff 6 Sep 12 10:56 original

$ ls -l --time-style=full-iso original    # 秒まで表示する
-rw-rw-r--. 1 staff staff 6 2019-09-12 10:56:37.783285724 +0900 original
```

| オプション | 表示される時刻 |
|:--|:--|
| `-l` | **mtime**（既定） |
| `-lu` | atime |
| `-lc` | ctime |
| `-lt` | mtime で並べ替え |
| `-lut` | atime で並べ替え |

## どのコマンドがどの時刻を更新するか

**`file` コマンドを使用すると、ファイルの最終変更時刻（mtime、ctime）は更新されませんが、
最終アクセス時刻（atime）は更新されます。**

中身を**読む**だけで、書き換えないためです。

```bash
$ stat original                     # 実行前の状態を確認する
Access: 2019-09-12 10:56:37.783285724 +0900
Modify: 2019-09-12 10:56:37.783285724 +0900
Change: 2019-09-12 10:56:37.783285724 +0900

$ file original                     # ファイルの種類を調べる（中身を読む）
original: ASCII text

$ stat original                     # 実行後の状態を確認する
Access: 2019-09-12 10:57:25.284354717 +0900    ← アクセス時刻（atime）のみ更新された
Modify: 2019-09-12 10:56:37.783285724 +0900    ← 変わっていない
Change: 2019-09-12 10:56:37.783285724 +0900    ← 変わっていない
```

### コマンド別の早見表

| コマンド | atime | mtime | ctime | 備考 |
|:--|:-:|:-:|:-:|:--|
| `file original` | **○** | ✗ | ✗ | 中身を読むだけ |
| `cat original` | **○** | ✗ | ✗ | 同上 |
| `less` / `head` / `tail` | **○** | ✗ | ✗ | 同上 |
| `grep pattern original` | **○** | ✗ | ✗ | 同上 |
| `echo "x" > original` | ✗ | **○** | **○** | 中身を書き換える |
| `echo "x" >> original` | ✗ | **○** | **○** | 追記も書き換え |
| `touch original` | **○** | **○** | **○** | **3 つとも更新される** |
| `chmod 644 original` | ✗ | ✗ | **○** | inode だけが変わる |
| `chown user original` | ✗ | ✗ | **○** | 同上 |
| `mv original new` | ✗ | ✗ | **○** | 名前（リンク）が変わる |
| `ls -l original` | ✗ | ✗ | ✗ | **中身を読まない** |

**押さえるべき法則**

1. **中身を読む** → atime だけ
2. **中身を書く** → mtime と ctime（読んでいないので atime は変わらない）
3. **属性を変える** → ctime だけ
4. **`touch`** → 3 つとも

**補足 … `ls` は更新しません**

`ls` はディレクトリの中の情報を見るだけで、ファイルの中身を開きません。
そのため、対象ファイルの atime は変わりません。

```bash
$ ls -l original                    # 一覧を見るだけ
-rw-rw-r--. 1 staff staff 6 Sep 12 10:56 original
$ stat -c '%x' original             # atime は変わっていない
2019-09-12 10:57:25.284354717 +0900
```

**補足 … リダイレクトで書き込むと atime は変わりません**

`echo "original" > original` は「開いて書く」だけで、**読んでいない**ためです。

```bash
$ echo "test" > original            # 中身を書き換える
$ stat original | grep -E 'Access:.*20|Modify|Change'    # 3つの時刻だけ抜き出す
Access: 2019-09-12 10:57:25.284354717 +0900    ← 変わらない
Modify: 2019-09-12 11:02:10.112233445 +0900    ← 更新された
Change: 2019-09-12 11:02:10.112233445 +0900    ← 更新された
```

## タイムスタンプを変更する

`touch` は本来「タイムスタンプを更新する」コマンドです。
ファイルが存在しない場合に、空のファイルを新規作成します。

```bash
$ touch original                    # atime と mtime を現在時刻にする
$ touch newfile.txt                 # 存在しなければ空ファイルを作る
```

### 主なオプション

| オプション | 意味 |
|:--|:--|
| `-a` | **atime だけ**を更新する |
| `-m` | **mtime だけ**を更新する |
| `-t [[CC]YY]MMDDhhmm[.ss]` | 指定した時刻にする |
| `-d 文字列` | 日時を文字列で指定する（`"2 days ago"` など） |
| `-r 基準ファイル` | 別のファイルと同じ時刻にする |
| `-c` | ファイルが無くても**作成しない** |

```bash
$ touch -m original                 # mtime だけを現在時刻にする
$ touch -t 202601011200 original    # 2026年1月1日 12:00 にする
$ touch -d "2 days ago" original    # 2日前の時刻にする
$ touch -r reference.txt original   # reference.txt と同じ時刻にする
$ touch -c nothing.txt              # 存在しなければ何もしない
```

### -t で指定する時刻の書式

`-t` に渡す時刻は **`CCYYMMDDhhmm.ss`** という形式の数字の並びです。
区切り文字はハイフンでもコロンでもなく、**秒の前のドットだけ**です。

```text
2 0 1 2 0 1 0 1 1 1 2 2 . 3 3
└┬┘ └┬┘ └┬┘ └┬┘ └┬┘ └┬┘   └┬┘
 CC  YY  MM  DD  hh  mm    ss
```

| 記号 | 意味 | 桁数 | 上の例 |
|:--|:--|:-:|:--|
| `CC` | 西暦年の**上 2 桁**（世紀） | 2 | `20` |
| `YY` | 西暦年の**下 2 桁** | 2 | `12` |
| `MM` | 月 | 2 | `01` |
| `DD` | 日 | 2 | `01` |
| `hh` | 時（24 時間制） | 2 | `11` |
| `mm` | 分 | 2 | `22` |
| `ss` | 秒（`.` で区切る） | 2 | `33` |

つまり `201201011122.33` は **2012年1月1日 11:22:33** を表します。

**例文** … `file.txt` の atime と mtime を 2012年1月1日 11:22:33 にする

```bash
$ touch -t 201201011122.33 file.txt      # 指定した時刻に変更する（無ければ新規作成）
$ stat file.txt                          # 結果を確認する
  File: file.txt
  Size: 0         	Blocks: 0          IO Block: 4096   regular empty file
Device: 254,0	Inode: 950321      Links: 1
Access: (0644/-rw-r--r--)  Uid: (    0/    root)   Gid: (    0/    root)
Access: 2012-01-01 11:22:33.000000000 +0000    ← atime。指定どおり
Modify: 2012-01-01 11:22:33.000000000 +0000    ← mtime。指定どおり
Change: 2026-08-31 15:15:58.485427809 +0000    ← ctime。現在時刻になる
```

**`-t` は `-a` も `-m` も付けなければ、atime と mtime の両方**を変更します。

**補足 … 省略できる部分**

`CC` と `ss` は省略できます。書式は正確には `[[CC]YY]MMDDhhmm[.ss]` です。

```bash
$ touch -t 202601011200 original         # CC と ss を省略（2026年1月1日 12:00:00）
$ touch -t 1201011122 original           # CC だけ省略した10桁 → 2012年1月1日 11:22
```

10 桁で書くと、先頭 2 桁は「月」ではなく **`YY`（西暦の下 2 桁）** として読まれます。
`1201011122` は「今年の 1 月 1 日」ではなく **2012 年 1 月 1 日**になる、というのがよくある勘違いです。

ただし**省略すると読み手が年を推測しづらくなる**ので、
手順書に書くときは `CCYYMMDDhhmm.ss` の 12 桁＋秒でフル指定するのが安全です。

**補足 … 時刻を指定しなければ現在時刻になります**

```bash
$ touch original                         # -t を付けない → 現在時刻になる
```

### 引数の順番を間違えるとどうなるか

`touch` の書式は次のとおりで、**オプション → 時刻 → ファイル名**の順です。

```text
touch [オプション] [-t 時刻] ファイル名 [ファイル名...]
```

**時刻をファイル名の後ろに書いた場合**

```bash
$ touch file.txt 201201011122.33         # -t が無いので、両方ともファイル名扱い
$ ls -l                                  # 数字の名前のファイルができてしまった
-rw-r--r-- 1 root root 0 Aug 31 15:15 201201011122.33
-rw-r--r-- 1 root root 0 Aug 31 15:15 file.txt
```

**`-t` を書かずに数字だけ並べると、その数字が「ファイル名」になります。**
`201201011122.33` という名前の空ファイルが新しく作られ、
`file.txt` のほうは（時刻指定が無いので）**現在時刻**に更新されます。
順序を入れ替えて `touch 201201011122.33 file.txt` としても、結果は同じです。

**`-at` / `-mt` と書いた場合**

```bash
$ touch -at 201201011122.33 f2.txt       # -a と -t をつなげて書いた
$ touch -mt 201201011122.33 f3.txt       # -m と -t をつなげて書いた
```

エラーにはなりません。**`-at` は `-a -t` の短縮形として解釈される**ためです。
ただし `-a` が効くので、**変わるのは atime だけ**になります。

```bash
$ stat -c '%n  atime=%x  mtime=%y' f2.txt f3.txt    # 結果を並べて確認する
f2.txt  atime=2012-01-01 11:22:33.000000000 +0000  mtime=2026-08-31 15:15:58.489427809 +0000
f3.txt  atime=2026-08-31 15:15:58.489427809 +0000  mtime=2012-01-01 11:22:33.000000000 +0000
```

| 書き方 | 実際の意味 | 変わるもの |
|:--|:--|:--|
| `touch -t 時刻 file` | `-t` のみ | **atime と mtime の両方** |
| `touch -at 時刻 file` | `-a -t 時刻` | **atime だけ** |
| `touch -mt 時刻 file` | `-m -t 時刻` | **mtime だけ** |

**両方を変えたいなら `-t` だけを付けます。**
`-a` や `-m` を足すと、片方に絞る指定になってしまいます。

**補足 … `ls -l` で見えているのは mtime です**

上の例で `f3.txt`（`-mt`）だけが `ls -l` で 2012年に見え、
`f2.txt`（`-at`）が現在時刻に見えるのはこのためです。
atime を見たいときは `ls -lu`、ctime は `ls -lc` を使います。

**`ctime` だけは自分で指定できません。**
`touch` で時刻を変えると、その操作自体が inode の変更なので **ctime は現在時刻になります**。

```bash
$ touch -t 202601011200 original    # mtime を過去に設定する
$ stat -c 'mtime=%y ctime=%z' original    # mtime と ctime を並べて確認する
mtime=2026-01-01 12:00:00.000000000 +0900
ctime=2026-08-31 23:45:12.334455667 +0900    ← ctime は現在時刻になる
```

**補足** … この性質のため、**ctime は改ざんの検知に使われます**。
mtime を偽装しても ctime は残るため、「いつ触られたか」の手がかりになります。

## 時刻を使ってファイルを探す

`find` はタイムスタンプで絞り込めます。棚卸しや掃除の定番です。

| オプション | 意味 |
|:--|:--|
| `-atime n` | atime が n 日前 |
| `-mtime n` | mtime が n 日前 |
| `-ctime n` | ctime が n 日前 |
| `-amin n` / `-mmin n` / `-cmin n` | 分単位で指定 |
| `-newer ファイル` | 指定ファイルより新しい |

**数字の書き方で意味が変わります。**

| 書き方 | 意味 |
|:--|:--|
| `-mtime 7` | ちょうど 7 日前（7 日以上 8 日未満） |
| `-mtime +7` | **7 日より前**（古い） |
| `-mtime -7` | **7 日以内**（新しい） |

```bash
$ find /var/log -name '*.log' -mtime +30       # 30日より前に更新されたログを探す
/var/log/old/app-202607.log

$ find /tmp -type f -atime +90                 # 90日以上読まれていないファイルを探す

$ find . -mmin -10                             # 10分以内に更新されたものを探す

$ find /var/log -name '*.gz' -mtime +90 -delete    # 90日より古い圧縮ログを削除する
```

**補足 … `-delete` の前に必ず一覧で確認します**

```bash
$ find /var/log -name '*.gz' -mtime +90        # まず対象を目で見る
$ find /var/log -name '*.gz' -mtime +90 -delete    # 確認してから消す
```

## アクセス時刻の更新は抑制されている

**現代の Linux では、atime は毎回は更新されません。**

読むたびにディスクへ書き込みが発生し、性能が落ちるためです。
多くのディストリビューションは **`relatime`** というマウントオプションを既定にしています。

| マウントオプション | atime の更新条件 |
|:--|:--|
| `strictatime` | **読むたびに**更新する（昔の動作） |
| **`relatime`** | 前回の atime が mtime/ctime より古い場合、または**24 時間以上経過**している場合だけ更新する |
| `noatime` | **まったく更新しない**（最も速い） |
| `nodiratime` | ディレクトリの atime だけ更新しない |

```bash
$ mount | grep ' / '                # ルートのマウントオプションを確認する
/dev/nvme0n1p1 on / type xfs (rw,relatime,seclabel,attr2,inode64)
                                    # ↑ relatime が既定になっている

$ grep ' / ' /etc/fstab             # 設定ファイル側も確認する
UUID=xxxx-xxxx / xfs defaults 0 0
```

**補足 … 試験と実機で挙動が違って見える理由がこれです**

「`file` を実行したら atime が更新される」というのは仕様どおりですが、
`relatime` の条件を満たさない場合、**実機では更新されないことがあります**。

```bash
$ stat -c '%x' original             # 実行前の atime
$ file original > /dev/null         # 読む
$ stat -c '%x' original             # 変わらないこともある（relatime のため）
```

厳密に確かめたい場合は、`strictatime` でマウントされた領域で試します。

**補足 … `noatime` は性能改善の定番です**

読み取りが多いサーバでは `noatime` にすると I/O が減ります。
ただし **atime に依存する処理（メールスプールや一部のバックアップツール）**が壊れることがあるため、
影響を確認してから設定します。

```bash
# /etc/fstab の例
UUID=xxxx-xxxx  /data  xfs  defaults,noatime  0 0
```
