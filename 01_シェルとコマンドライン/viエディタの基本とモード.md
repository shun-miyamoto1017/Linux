## viとは何か

**`vi`（ヴィーアイ）は Linux で標準的に使用されているテキストエディタ**です。

**なぜ `vi` を覚える必要があるのか。** 理由は 1 つです。

```text
  最小構成のサーバ         … nano も emacs も入っていない
  Docker コンテナの中      … 同上。vi すら無いこともある
  レスキューモード          … 使えるものが限られる
  他人が作ったサーバ        … 何が入っているか分からない

  → どこにでもあるのは vi だけ
```

**実務では「使いこなす」必要はありません。**
**設定ファイルを開いて、1 行直して、保存して閉じる**。これができれば十分です。

## 起動する

```text
vi [-R] [ファイル名]
```

```bash
$ vi /etc/hosts                       # 既存のファイルを開く
$ vi                                  # ファイル名なしで起動する（空のファイルが開く）
$ vi -R /etc/passwd                   # 読み取り専用で開く
```

### 起動時のオプション

| オプション | 意味 |
|:--|:--|
| **`-R`** | **読み取り専用で開く**（誤って書き換えないため） |
| `+行番号` | 指定した行にカーソルを置いて開く（例 `vi +50 file`） |
| `+/文字列` | 指定した文字列を検索した位置で開く |
| `-r` | クラッシュ後にスワップファイルから復旧する |

```bash
$ vi +50 /etc/nginx/nginx.conf        # 50行目を表示した状態で開く
$ vi +/ServerName httpd.conf          # ServerName を検索した位置で開く
```

**補足 … ファイル名を指定しない場合**

**空のファイルが開き、保存するときにファイル名を付けます**（`:w ファイル名`）。
「無題」の状態で編集を始められる、という意味です。

### 存在しないファイル名を指定したとき

**エラーにはなりません。** その名前で**空のファイルが開きます**。

```bash
$ vi test.txt                         # test.txt が存在しない状態で起動する
```

```text
~ 空 ~




"test.txt" [New]                   0,0-1        All
```

**画面下部の `[New]`** が「これは新規ファイルです」という表示です。
**この時点ではまだディスク上にファイルは作られていません。**
保存（`:w`）して初めて作成されます。

**そして起動直後は必ずコマンドモード**です。文字を打ってもテキストは入りません。

| 起動のしかた | 開かれるもの | 起動直後のモード |
|:--|:--|:--|
| `vi 既存ファイル` | そのファイルの内容 | **コマンドモード** |
| **`vi 存在しないファイル`** | **その名前の空のファイル** | **コマンドモード** |
| `vi`（ファイル名なし） | 無名の空のファイル | **コマンドモード** |

## 二つの動作モード

**`vi` には 2 つの動作モードがあります。** ここが最初の関門です。

| モード | できること |
|:--|:--|
| **コマンドモード** | **カーソルの移動、テキストのコピー＆ペースト、ファイルの保存など** |
| **入力モード** | **テキスト本文の編集**（文字を打ち込む） |

**普通のエディタと決定的に違うのは、「文字を打つ」ことが特別なモードでしか
できない**点です。コマンドモードで `d` を押すと文字が入るのではなく、削除の操作が始まります。

```text
   起動
    │
    ▼
  ┌──────────────────┐  i / a / o など  ┌────────────────┐
  │  コマンドモード  │ ---------------> │   入力モード   │
  │ （移動・削除・   │                  │ （文字を打つ） │
  │   保存・検索）   │ <--------------- │                │
  └──────────────────┘       Esc        └────────────────┘
```

**迷ったら `Esc` を押してください。** コマンドモードに戻ります。
コマンドモードで `Esc` を押しても何も起きないので、**何度押しても安全**です。

### いまどちらのモードかを見分ける

**画面のいちばん下（ステータス行）を見ます。**

**コマンドモード**

```text
…（略）
rtkit:x:499:499:RealtimeKit:/proc:/sbin/nologin
abrt:x:498:498::/etc/abrt:/sbin/nologin
nscd:x:28:28:NSCD Daemon:/:/sbin/nologin
"/etc/passwd" 37L, 1780B          ← ファイル名と行数・バイト数が出ている
```

**入力モード**

```text
…（略）
rtkit:x:499:499:RealtimeKit:/proc:/sbin/nologin
abrt:x:498:498::/etc/abrt:/sbin/nologin
nscd:x:28:28:NSCD Daemon:/:/sbin/nologin
-- INSERT --                      ← これが出ていたら入力モード
```

| ステータス行の表示 | いまのモード |
|:--|:--|
| **`-- INSERT --`** | **入力モード** |
| **`-- REPLACE --`** | 上書き入力モード（`R` で入る） |
| **`-- VISUAL --`** | 選択モード（`v` で入る。vim の機能） |
| **ファイル名や行数** | **コマンドモード** |
| **`:` だけ**（左下） | コマンドモードで `:` を押し、コマンド入力を待っている状態 |

**`-- INSERT --` が出ていないのに文字が消えていく**というのが、
初心者がいちばんよく遭遇する事故です。コマンドモードで打鍵していることが原因なので、
まず `Esc` を押し、`u`（元に戻す）で戻してください。

### モードを切り替える

| やりたいこと | キー |
|:--|:--|
| **コマンドモード → 入力モード** | **`i` `a` `I` `A` `o` `O` など**（次節） |
| **入力モード → コマンドモード** | **`Esc`** |

**入力モードから戻るキーは、実質 `Esc` だけ**と覚えてください。
`Alt` でも `Tab` でも `Shift` でも戻れません
（`Ctrl+[` は端末上 `Esc` と同じコード、`Ctrl+c` でも戻れますが、
試験でも実務でも `Esc` 一本で通します）。

## 入力モードへ移行するコマンド

**コマンドモードから入力モードへ移行するには、次のコマンドを使います。**
どれも「どこから入力を始めるか」が違うだけです。

| コマンド | 説明 |
|:--|:--|
| **`i`** | **カーソルの左から入力開始**（insert） |
| **`a`** | **カーソルの右から入力開始**（append） |
| **`I`** | **カーソルのある行の先頭から入力開始** |
| **`A`** | **カーソルのある行の末尾から入力開始** |
| **`o`** | **カーソルのある行の下に空白行を挿入し、その行から入力開始**（open） |
| **`O`** | **カーソルのある行の上に空白行を挿入し、その行から入力開始** |

```text
   カーソルが「c」の上にあるとき   a b [c] d e

     i を押す  →  a b | c d e      ← c の左から入力が始まる
     a を押す  →  a b c | d e      ← c の右から入力が始まる
     I を押す  →  | a b c d e      ← 行の先頭
     A を押す  →  a b c d e |      ← 行の末尾
```

**まず覚えるのは `i` と `a` と `o` の 3 つ**です。

| 場面 | 使うキー |
|:--|:--|
| いまの位置に書き足す | **`i`** |
| 行の最後に書き足す | **`A`** |
| 新しい行を書く | **`o`** |

**補足 … `i` と `a` の使い分けに悩む必要はありません**

**行末に文字を足したいとき、`i` では 1 文字手前にしか入りません。**
`A` を使えば一発で行末に行けるので、**「行末に足す＝`A`」**と覚えるのがいちばん実用的です。

## カーソルを動かす

**カーソル移動はコマンドモードで行います。**

### 文字単位で動かす

| コマンド | 説明 |
|:--|:--|
| **`h`** | **1文字左へ移動** |
| **`l`** | **1文字右へ移動** |
| **`k`** | **1行上へ移動** |
| **`j`** | **1行下へ移動** |

```text
        k（上）
        ↑
 h ←        → l
（左）  ↓   （右）
        j（下）
```

**覚え方** … キーボードのホームポジションで**左から順に `h j k l`** が並んでいます。
**いちばん左の `h` が左**、**いちばん右の `l` が右**。
残る `j` と `k` は、**`j` の形が下向きのフック**なので下、と覚えます。

**矢印キーでも動きます。** 現代の環境ではまず動くので、
**まずは矢印キーで構いません**。`hjkl` は慣れてからで十分です。

```bash
$ vi p.txt                            # line1〜line4 の4行を開く
```

```text
line1
line2
line3
line4
~
"p.txt" 4L, 24B              1,1     All   ← 起動直後は 1 行 1 桁

   gg → j を1回   →  ステータス行が 2,1 になる（2行目の1桁目）
   gg → k を1回   →  1,1 のまま（1行目より上へは行けない／エラーも出ない）
```

**`h` や `k` は端に来ると止まります**（エラーにはなりません）。
1 行目で `k` を押しても 1 行目のまま、1 桁目で `h` を押しても 1 桁目のままです。

### 行内で動かす

| コマンド | 説明 |
|:--|:--|
| **`0`（ゼロ）** | **行頭へ移動** |
| **`$`** | **行末へ移動** |
| `^` | 行頭の**空白を除いた**最初の文字へ移動 |
| `w` | 次の単語の先頭へ |
| `b` | 前の単語の先頭へ |
| `e` | 単語の末尾へ |

**`0` は数字のゼロ**です。アルファベットの `O`（オー）ではありません。
`O` を押すと上に空行が入って入力モードになってしまいます。

**`0` と `^` の違い**

```text
       ␣␣␣␣hello world
       ↑   ↑
       0   ^
    行頭   最初の「文字」
```

インデントされた設定ファイルでは `^` のほうが便利なことが多いです。

### 行を飛ばす

| コマンド | 説明 |
|:--|:--|
| **`gg`** | **ファイルの先頭へ移動** |
| **`G`** | **ファイルの最終行へ移動** |
| **`nG`** | **ファイルの n 行目へ移動**（例 `10G` で10行目） |
| **`:n`** | **ファイルの n 行目へ移動**（例 `:10`） |

**`nG` と `:n` は同じ動き**です。どちらで覚えても構いません。

```bash
$ vi /var/log/messages                # 長いログファイルを開いて
                                      # G で最終行（＝最新のログ）へ一気に飛ぶ
```

**ログを開いたらまず `G`** です。最新の行が末尾にあるためです。

### 画面を動かす

| コマンド | 説明 |
|:--|:--|
| **`H`** | **画面の最上行へ移動**（High） |
| **`L`** | **画面の最下行へ移動**（Low） |
| `M` | 画面の中央行へ移動（Middle） |
| **`Ctrl+b`** | **1画面分、上方を表示**（backward） |
| **`Ctrl+f`** | **1画面分、下方を表示**（forward） |
| `Ctrl+u` | 半画面分、上へ（up） |
| `Ctrl+d` | 半画面分、下へ（down） |

**`H` `L` は「画面の中で」動く、`Ctrl+b` `Ctrl+f` は「画面そのもの」を動かす**という違いです。

### 数字を前に付けて繰り返す

**コマンドの前に数字を付けると、その回数分コマンドが繰り返されます。**

```text
   5k   →  カーソルが 5 行上へ移動する
   3j   →  3 行下へ
   10l  →  10 文字右へ
```

**この「数字＋コマンド」は vi 全体で共通の仕組み**です。
移動だけでなく、削除（`3dd`）やコピー（`3yy`）でも同じように働きます
（[viエディタの編集操作](./viエディタの編集操作.md)）。

**補足 … 数が足りないときの動き**

3 行しかないファイルで `5k` を押しても、**エラーにはならず 1 行目で止まります**。
**回数付きの編集コマンドも考え方は同じ**で、**足りない分は無視して「あるだけ」実行されます**。
3 行のファイルで `5dd` を押すと 3 行すべてが消え、`abcdef` の行頭で `10x` を押すと
6 文字すべてが消えます（実測）。「5 行そろっていないから何も起きない」ということはありません。

## 結果画面の見方

`vi` の画面は**本文領域**と、いちばん下の**ステータス行**に分かれます。

```text
root:x:0:0:root:/root:/bin/bash
bin:x:1:1:bin:/bin:/sbin/nologin        ← 本文領域
daemon:x:2:2:daemon:/sbin:/sbin/nologin
~
~                                        ← ファイルの終端より後ろは ~ が並ぶ
"/etc/passwd" 37L, 1780B     2,11    All  ← ステータス行
```

| 表示 | 意味 |
|:--|:--|
| **`~`**（チルダ） | **ファイルの終端より後ろ**。空行ではなく「行が存在しない」という印 |
| **`"/etc/passwd"`** | 開いているファイル名 |
| **`37L, 1780B`** | **37 行、1780 バイト**（Lines と Bytes）。vim 7 世代では `1780C`（文字数）と表示されていた |
| **`[New]`** | **新規ファイル**（まだディスクに存在しない）。vim 7 世代では `[New File]` と表示されていた |
| `[readonly]` | **読み取り専用で開いている**。`"file" [readonly] 30L, 1483B` のようにファイル名の直後に出る |
| **`2,11`** | **カーソル位置**（行番号, 桁番号） |
| `0,0-1` | 空ファイルのときの表示 |
| **`All` / `Top` / `Bot` / `45%`** | **いまファイルのどのあたりを見ているか** |

**`~` を「空行」と誤解しやすい**ので注意してください。
`~` の行にカーソルを動かすことはできません。

## viとvimの関係

**現代の Linux で `vi` と打つと、実際には `vim`（Vi IMproved）が起動することがほとんど**です。

| | **vi（オリジナル）** | **vim** |
|:--|:--|:--|
| 元祖 | 1976年、BSD | 1991年、vi の改良版 |
| 元に戻す（`u`） | **1回だけ** | **何回でも** |
| 矢印キー | 使えないことがある | **使える** |
| 構文の色付け | なし | **あり** |
| 分割画面・タブ | なし | あり |

```bash
$ ls -l /usr/bin/vi                   # vi の実体を確認する
lrwxrwxrwx 1 root root 20 … /usr/bin/vi -> /etc/alternatives/vi
```

**RHEL 系で最小構成インストールすると `vim` が入っていないことがあります。**
その場合は `vi`（`vim-minimal` が提供する簡易版）だけが使えます。

**Ping-t の試験では「vi の機能」として出題される**ため、
**vim にしかない機能に頼らない**のが安全です。このノートも vi の範囲で書いています。
