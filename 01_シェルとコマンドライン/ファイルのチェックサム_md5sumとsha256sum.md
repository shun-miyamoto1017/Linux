## メッセージダイジェストとは

**メッセージダイジェスト（ハッシュ値）とは、入力データからハッシュ関数で計算される固定長の値**です。

```text
   どんなに大きいファイルでも  ──[ハッシュ関数]──▶  決まった長さの値
      3 バイト                                       b1946ac92492d2347c6235b4d2611184
      3 ギガバイト                                   9a929dc52cdcb99b173e5183a3b7571c
```

**性質は 3 つ**です。

| 性質 | 意味 |
|:--|:--|
| **長さが一定** | 入力が何バイトでも、出力は同じ桁数 |
| **同じ入力なら必ず同じ値** | いつ・どのマシンで計算しても一致する |
| **1 ビットでも変われば値が大きく変わる** | **改ざん・破損の検知**に使える |

**「ファイルが同じかどうか」を、中身を見ずに数字だけで判定できる**のが利点です。
ネットワーク越しにファイルを比べたいときに効きます。

## 3つのコマンド

**書式はどれも同じ**です。

```text
コマンド [オプション] ファイル名
```

| コマンド | アルゴリズム | ビット長 | 16進の桁数 |
|:--|:--|--:|--:|
| **`md5sum`** | **MD5** | **128** | **32** |
| `sha1sum` | SHA-1 | 160 | 40 |
| **`sha256sum`** | **SHA-256** | **256** | **64** |
| **`sha512sum`** | **SHA-512** | **512** | **128** |

**名前の数字がそのままビット長**です。**`md5sum` だけ 128 ビット**なので、そこだけ覚えてください。

```text
   md5sum      →  MD5      →  128 ビット
   sha256sum   →  SHA-256  →  256 ビット
   sha512sum   →  SHA-512  →  512 ビット
```

**`md5check` `checkmd5` `sha256check` `calc256` といったコマンドは存在しません。**
試験では誤答として出ます。

## 値を計算する

```bash
$ echo "hello" > file1                # 確認用のファイル
$ md5sum file1                        # MD5 を計算する
b1946ac92492d2347c6235b4d2611184  file1
$ sha256sum file1                     # SHA-256 を計算する
5891b5b522d5df086d0ff0b110fbd9d21bb4fc7163af34d08286a2e846f6be03  file1
```

**出力は「ハッシュ値」＋「空白 2 つ」＋「ファイル名」**です。

```text
   b1946ac92492d2347c6235b4d2611184  file1
   └───────────┬──────────────────┘  └─┬─┘
          ハッシュ値（16進32桁）    ファイル名
```

**空白は 2 つ**で、間の 2 文字目は入力モードを表します。

| 2 文字目 | 意味 |
|:-:|:--|
| **空白** | **テキストモード**（既定） |
| `*` | バイナリモード（`-b` を付けたとき） |

```bash
$ md5sum -b file1                     # バイナリモードで読むと * が付く
b1946ac92492d2347c6235b4d2611184 *file1
```

**Linux では両者に違いはありません。** Windows との互換のために残っている区別です。

**標準入力から読むこともできます。**

```bash
$ echo "hello" | md5sum               # パイプから読むとファイル名は - になる
b1946ac92492d2347c6235b4d2611184  -
```

## 一覧ファイルを作って照合する

**複数ファイルを渡すと、1 行ずつ出力**されます。
**これをそのままファイルに落とせば、照合用の一覧になります。**

```bash
$ echo "world" > file2                      # 2つ目と3つ目も用意する
$ echo "again" > file3                      # 3つ目
$ md5sum file1 file2 file3 > checksum.txt   # 3つの値を一覧に書き出す
$ cat checksum.txt                          # 中身を確かめる
b1946ac92492d2347c6235b4d2611184  file1
591785b794601e212b260e25925636fd  file2
9a929dc52cdcb99b173e5183a3b7571c  file3
```

### 照合オプション

**`-c`（`--check`）で、一覧ファイルの値と実ファイルを突き合わせます。**

| オプション | 意味 |
|:--|:--|
| **`-c`** / **`--check`** | **一覧ファイルを読み込んで照合する** |
| `--quiet` | 一致したファイルの `OK` を出さない（失敗だけ表示） |
| `--status` | 何も表示しない（**終了ステータスだけで判定**する。スクリプト向け） |
| `--ignore-missing` | 一覧にあってもファイルが無い場合、失敗にしない |
| `--strict` | 一覧の書式が壊れていたら終了ステータスを 0 以外にする |
| `-b` | バイナリモードで読む |

```bash
$ md5sum -c checksum.txt              # 一覧と突き合わせる
file1: OK
file2: OK
file3: OK
$ echo $?                             # すべて一致なら 0
0
```

**`-c` に渡すのは「一覧ファイル」であって「検証したいファイル」ではありません。**
ここが試験で狙われます。

```bash
$ md5sum -c checksum.txt              # 一覧ファイルを渡す（正しい）
file1: OK
file2: OK
file3: OK
$ md5sum -c file1                     # 検証したいファイルを渡してしまうと…
md5sum: file1: no properly formatted checksum lines found
$ echo $?                             # 終了ステータスは 1
1
```

**`file1` の中身をハッシュ一覧として読もうとして失敗**しています。

### 壊れていたときの出力

```bash
$ echo "tampered" > file2             # file2 を書き換えてしまう
$ md5sum -c checksum.txt              # もう一度照合する
file1: OK
file2: FAILED
file3: OK
md5sum: WARNING: 1 computed checksum did NOT match
$ echo $?                             # 不一致があると 1 になる
1
```

**`FAILED` の行と、末尾の `WARNING` の 2 か所に出ます。**
**日本語環境では `完了` / `失敗` と表示される**ことがあります。

| 表示 | 意味 |
|:--|:--|
| **`OK`**（`完了`） | **値が一致した** |
| **`FAILED`**（`失敗`） | **値が違う**＝壊れているか、書き換えられている |
| `FAILED open or read` | **ファイルが無い**か、読めない |

```bash
$ md5sum -c miss.txt                  # 一覧にあるファイルが存在しない場合
md5sum: nope.txt: No such file or directory
nope.txt: FAILED open or read
md5sum: WARNING: 1 listed file could not be read
```

## スクリプトで使う

**画面表示ではなく終了ステータスで判定したいときは `--status`** を使います。

```bash
$ md5sum --status -c checksum.txt     # 何も出さずに判定だけする
$ echo $?                             # 画面には何も出ない。不一致があれば 1
1
$ md5sum --quiet -c checksum.txt      # 失敗した行だけ見たいとき
file2: FAILED
md5sum: WARNING: 1 computed checksum did NOT match
```

**検証を組み込んだ配布の受け取り手順**はこの形になります。

```bash
$ md5sum --status -c checksum.txt && echo "検証OK" || echo "検証NG"   # 判定して分岐する
```

**`&&` と `||` の使い分け**は
[コマンドの連結と制御演算子](./コマンドの連結と制御演算子.md) にまとめています。

**補足 … 1 ファイルだけ確かめたいとき**

**公開されている値を手で貼り付けて比べる**のが手早いです。

```bash
$ sha256sum linux.iso                 # 手元の値を計算する
5891b5b522d5df086d0ff0b110fbd9d21bb4fc7163af34d08286a2e846f6be03  linux.iso
```

**目で比べると見落とすので、一覧ファイルを作って `-c` に通す**ほうが確実です。

```bash
$ echo "5891b5b5...be03  linux.iso" > iso.sha256   # 公開値を貼って一覧を作る
$ sha256sum -c iso.sha256                          # 機械に比べさせる
linux.iso: OK
```

## MD5 を使ってよい場面と悪い場面

**MD5 は「衝突」（違うデータから同じ値が出ること）を意図的に作れることが知られています。**
そのため **用途によって使い分け**が必要です。

| 用途 | MD5 | SHA-256 以上 |
|:--|:-:|:-:|
| **転送で壊れていないかの確認** | **○** | ○ |
| **同じファイルかどうかの照合** | **○** | ○ |
| **改ざんされていないかの検証** | **✕** | **○** |
| **署名・証明書** | **✕** | **○** |

**「事故を検知する」なら MD5 で十分**ですが、
**「悪意を検知する」なら SHA-256 以上**を使ってください。

**配布元が SHA-256 の値を公開しているなら、そちらに合わせる**のが正解です。

## 実務での使い方

| やりたいこと | 書き方 |
|:--|:--|
| **ISO を検証する** | `sha256sum -c ubuntu.iso.sha256` |
| **転送前後で一致を確かめる** | 両側で `md5sum ファイル` を実行して見比べる |
| **ディレクトリ全体の一覧を作る** | `find . -type f -exec sha256sum {} + > all.sha256` |
| **一覧と突き合わせる** | `sha256sum -c all.sha256` |
| **失敗したものだけ見る** | `sha256sum --quiet -c all.sha256` |
| **重複ファイルを見つける** | `find . -type f -exec md5sum {} + \| sort \| uniq -w32 -d` |
| **1ファイルだけ標準入力から** | `cat file \| sha256sum` |

**最後の例の `uniq -w32`** は「先頭 32 文字（＝MD5 の値）だけを比較する」という意味です
（[sortによる並べ替え](../02_テキスト処理と正規表現/sortによる並べ替え.md)）。

**注意 … 一覧ファイル自体も守ってください**

**ファイルと一覧ファイルが同じ場所にあると、両方まとめて書き換えられます。**
**一覧は別の経路（配布元の web サイト、署名付きメールなど）で受け取る**のが本来の使い方です。

```text
   × 同じサーバから  file.iso  と  file.iso.md5  を落とす
       → サーバが乗っ取られていたら両方すり替えられる

   ○ ファイルはミラーから、値は配布元の公式サイトから
```
