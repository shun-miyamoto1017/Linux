## man コマンドの書式

Linux では、コマンドや設定ファイルのためのオンラインマニュアルページ（man ページ）が用意されています。
**オンラインマニュアルを参照するコマンドは `man`** です。

```
man [オプション] [セクション番号] キーワード
```

| オプション | 説明 |
|:--|:--|
| `-k` | キーワードに**一部一致**するコマンドやファイルの man ページを一覧表示（`apropos` コマンドと同じ） |
| `-f` | キーワードに**完全一致**するコマンドやファイルの man ページを一覧表示（`whatis` コマンドと同じ） |

**例文**

```bash
$ man ls                            # ls コマンドのマニュアルを開く
LS(1)                        User Commands
NAME
       ls - list directory contents
...

$ man -k password                   # 「password」を含む man ページを一覧表示
passwd (1)           - change user password
passwd (5)           - the password file
chpasswd (8)         - update passwords in batch mode

$ man -f passwd                     # 「passwd」に完全一致する man ページを一覧表示
passwd (1)           - change user password
passwd (5)           - the password file
```

**補足** … `-k` は「うろ覚えのときに探す」、`-f` は「どのセクションにあるか確かめる」ための
オプションです。前者は候補が大量に出ることがあるので `grep` と併用します。

```bash
$ man -k network | grep '(8)'       # セクション8（管理コマンド）に絞って探す
ip (8)               - show / manipulate routing, network devices...
ss (8)               - another utility to investigate sockets
```

## セクション番号

同じキーワードに man ページが複数用意されている場合があります
（例えば `passwd` コマンドと「`/etc/passwd`」ファイル）。
このような場合は、**セクション番号を指定して `man` コマンドを実行する**ことで、
目的の man ページを参照することが出来ます。

**セクション番号を指定しないで実行した場合は、セクション番号の小さいほうのマニュアルが表示されます。**

man ページのセクション番号は以下の通りです。

| セクション番号 | 内容 |
|:-:|:--|
| 1 | ユーザーコマンド |
| 2 | システムコール（カーネルが提供する関数） |
| 3 | ライブラリ呼び出し（プログラムライブラリに含まれる関数） |
| 4 | 特殊ファイル（通常 `/dev` 配下に存在するファイル） |
| 5 | **ファイルの書式と慣習**（例: `/etc/passwd`） |
| 6 | ゲーム |
| 7 | その他いろいろなもの（マクロパッケージや慣習などを含む）例えば man(7) や groff(7) |
| 8 | システム管理コマンド（通常は root 用） |
| 9 | カーネルルーチン［非標準］ |

**例文**

```bash
$ man passwd                        # 番号を省略 → 小さいほうのセクション1が開く
PASSWD(1)                    User Commands
       passwd - change user password

$ man 5 passwd                      # セクション5を指定 → /etc/passwd の書式が開く
PASSWD(5)                    File Formats and Conversions
       passwd - the password file
```

**補足 … 「コマンド」か「設定ファイル」かで番号を選ぶ**

同じ名前でも、**実行するもの**はセクション 1 または 8、
**中身を書くファイル**はセクション 5 に載っています。

```bash
$ man -f crontab                    # crontab に用意されている man ページを確認
crontab (1)          - maintain crontab files for individual users
crontab (5)          - tables for driving cron

$ man 1 crontab                     # crontab コマンド（-e -l -r などの使い方）
$ man 5 crontab                     # /etc/crontab に書く分・時・曜日の書式
```

「`/etc/crontab` の書き方を知りたい」なら **5**、
「`crontab -e` の使い方を知りたい」なら **1** です。

## セクションごとの中身を実際に見る

番号を丸暗記するより、実際に開いて中身を見たほうが記憶に残ります。

### 1 … ユーザーコマンド

一般ユーザが実行するコマンドのマニュアルです。日常で最もよく開きます。

```bash
$ man 1 ls                          # ls のオプション一覧
$ man 1 grep                        # grep の正規表現とオプション
$ man 1 crontab                     # crontab コマンドの使い方
CRONTAB(1)                   User Commands
       crontab - maintain crontab files for individual users
```

### 2 … システムコール

カーネルが提供する関数のマニュアルです。C 言語からカーネルを呼ぶときに参照します。
インフラ視点では、`strace` の出力を読むときに役立ちます。

```bash
$ man 2 open                        # ファイルを開くシステムコール
OPEN(2)                      Linux Programmer's Manual

$ man 2 kill                        # プロセスにシグナルを送るシステムコール
                                    # ※ man 1 kill は kill コマンドのほう
```

### 3 … ライブラリ呼び出し

プログラムライブラリに含まれる関数のマニュアルです。

```bash
$ man 3 printf                      # C言語の printf 関数
PRINTF(3)                    Linux Programmer's Manual

$ man 1 printf                      # 同じ名前でもセクション1はコマンドの printf
PRINTF(1)                    User Commands
```

### 4 … 特殊ファイル

通常 `/dev` 配下に存在するファイルのマニュアルです。

```bash
$ man 4 null                        # /dev/null の説明
NULL(4)                      Device Drivers Manual
       null, zero - data sink

$ man 4 random                      # /dev/random と /dev/urandom の違い
```

### 5 … ファイルの書式と慣習

**設定ファイルの書き方**が載っています。インフラ運用で最も価値が高いセクションです。

```bash
$ man 5 crontab                     # /etc/crontab の書式
$ man 5 fstab                       # /etc/fstab のフィールドの意味
$ man 5 sshd_config                 # sshd の全設定項目
$ man 5 resolv.conf                 # 名前解決の設定
$ man 5 hosts                       # /etc/hosts の書式
```

### 6 … ゲーム

ゲームのマニュアルです。実務でもクラウド運用でも、まず使いません。

```bash
$ man 6 intro                       # セクション6の概要ページ
INTRO(6)                     Games Manual
```

### 7 … その他いろいろなもの

マクロパッケージや慣習など、上のどれにも入らないものです。
**規約や仕様の解説が入っているため、意外と読む価値があります。**

```bash
$ man 7 hier                        # ファイルシステム階層（どのディレクトリに何を置くか）
HIER(7)                      Linux Programmer's Manual
       hier - description of the filesystem hierarchy

$ man 7 signal                      # シグナルの一覧と意味（SIGTERM / SIGKILL など）
$ man 7 regex                       # POSIX 正規表現の仕様
$ man 7 glob                        # パス名展開の仕様
```

### 8 … システム管理コマンド

通常は root が使う管理コマンドのマニュアルです。

```bash
$ man 8 mount                       # mount コマンド
MOUNT(8)                     System Administration

$ man 8 crond                       # cron デーモンそのもの
$ man 8 sshd                        # SSH デーモン
$ man 8 iptables                    # パケットフィルタ
```

### 9 … カーネルルーチン［非標準］

カーネル内部のルーチンのマニュアルです。非標準なので、多くのディストリでは存在しません。

```bash
$ man 9 intro                       # 環境によっては存在しない
No manual entry for intro in section 9
```

## man ページの中での操作

man ページの表示には `less` が使われているため、**`less` と同じキー操作**がそのまま使えます。

| キー | 動作 |
|:--|:--|
| `スペース` / `f` | 次のページへ |
| `b` | 前のページへ |
| `↓` / `↑` | 1 行ずつ移動 |
| `g` | 先頭へ |
| `G` | 末尾へ |
| `/文字列` | 下方向へ検索 |
| `?文字列` | 上方向へ検索 |
| `n` / `N` | 次の / 前の検索結果へ |
| `h` | ヘルプ（キー操作の一覧） |
| `q` | 終了 |

**補足 … 目的のオプションを一発で探す**

長い man ページからオプションを探すときは、`/` に続けて
**「スペース＋ハイフン＋文字」** で検索すると当たりやすくなります。

```bash
$ man ls                            # ls のマニュアルを開く
/ -h                                # 「 -h」を検索（オプションの説明にたどり着く）
n                                   # 次の候補へ
q                                   # 終了
```

> `less` の詳しい操作は
> [ファイルの内容を見るコマンド](./ファイルの内容を見るコマンド.md) を参照してください。

## man ページの構成

man ページはどれも同じ見出し構成になっています。**順番を知っていると読むのが速くなります。**

| 見出し | 内容 |
|:--|:--|
| `NAME` | コマンド名と一行説明 |
| `SYNOPSIS` | 書式（どんな引数を取るか） |
| `DESCRIPTION` | 詳しい説明 |
| `OPTIONS` | オプションの一覧 |
| `EXIT STATUS` | 終了ステータスの意味 |
| `ENVIRONMENT` | 影響する環境変数 |
| `FILES` | 関連する設定ファイル |
| `EXAMPLES` | 使用例（あると非常に助かる） |
| `SEE ALSO` | 関連する man ページ |

**`SYNOPSIS` の読み方**

```
ls [OPTION]... [FILE]...
```

| 表記 | 意味 |
|:--|:--|
| `[ ]` | **省略できる** |
| `...` | 複数回**繰り返せる** |
| `\|` | どちらか一方を選ぶ（縦棒） |
| 下線 or 太字 | そのまま入力する文字 |

**補足** … 急いでいるときは `EXAMPLES` と `SEE ALSO` から見ると早いです。
`SEE ALSO` には関連コマンドが載っているため、「近いことをする別のコマンド」を探すのにも使えます。

```bash
$ man ip                            # ip コマンドのマニュアルを開く
/SEE ALSO                           # SEE ALSO まで飛ぶ
                                    # ip-address(8), ip-route(8) などが載っている
$ man 8 ip-route                    # サブコマンドごとに独立した man ページがある
```

## キーワードから探す

コマンド名を思い出せないときは、**やりたいことのキーワードから探せます**。

```bash
$ man -k "disk space"               # 「disk space」を含む man ページを探す
df (1)               - report file system disk space usage
du (1)               - estimate file space usage

$ apropos "disk space"              # man -k と同じ（apropos は「関連する」の意）
df (1)               - report file system disk space usage
du (1)               - estimate file space usage

$ whatis df                         # man -f と同じ（一行説明だけ表示）
df (1)               - report file system disk space usage
```

| コマンド | 同じ意味の書き方 | 動作 |
|:--|:--|:--|
| `man -k キーワード` | `apropos キーワード` | **一部一致**で検索 |
| `man -f キーワード` | `whatis キーワード` | **完全一致**で検索 |

**補足 … 本文まで検索する `-K`（大文字）**

`-k` は「名前と一行説明」しか見ませんが、**`-K`（大文字）は man ページの本文全体**を検索します。
時間はかかりますが、「あのオプション、どのコマンドだったか」を探すときに有効です。

```bash
$ man -K "bind9"                    # 本文に bind9 を含む man ページを順に提示する
```

**補足 … データベースが古いと見つからない**

`man -k` / `apropos` は事前に作られた索引データベースを使います。
新しくインストールしたコマンドが見つからない場合は、データベースを更新します。

```bash
$ sudo mandb                        # 索引データベースを更新する（RHEL系 / Debian系 共通）
```

## man 以外のマニュアル

### `--help`

多くのコマンドは `--help` で簡易ヘルプを表示します。**man より速く、要点だけ見られます。**

```bash
$ ls --help | head -10              # 簡易ヘルプの先頭10行を見る
Usage: ls [OPTION]... [FILE]...
List information about the FILEs (the default is the current directory).

$ ls --help | grep -- '-h'          # 特定のオプションだけ探す
  -h, --human-readable       with -l and -s, print sizes like 1K 234M 2G
      --help                 display this help and exit
```

**注意** … `--help` を持たないコマンドもあります。その場合は `-h` や引数なしで起動を試します。
ただし、**引数なしで起動すると実行されてしまうコマンドもある**ので、まず `man` を見るのが安全です。

### `info`

GNU 製のコマンドには、man より詳しい `info` 文書が用意されていることがあります。

```bash
$ info coreutils                    # GNU coreutils の詳細ドキュメント
$ info bash                         # bash の完全なマニュアル
```

| キー | 動作 |
|:--|:--|
| `スペース` | 次のページへ |
| `n` / `p` | 次 / 前のノードへ |
| `u` | 一つ上の階層へ |
| `q` | 終了 |

**補足** … `info` はハイパーリンク構造になっており、man より情報量が多い一方で
操作を覚える必要があります。**まず `man`、足りなければ `info`** という順で十分です。

### `/usr/share/doc`

パッケージ付属のドキュメント（README、設定例、変更履歴）が置かれています。

```bash
$ ls /usr/share/doc/ | head -5      # ドキュメントが用意されているパッケージ一覧
$ ls /usr/share/doc/nginx/          # nginx のドキュメントを確認
$ zcat /usr/share/doc/nginx/CHANGES.gz | head    # 圧縮されている場合は zcat で読む
```

**補足** … `.gz` で圧縮されていることが多いため、`zcat` `zless` `zgrep` を使います。

```bash
$ zless /usr/share/doc/openssh/README.gz    # 圧縮ファイルを less と同じ操作で読む
```

### `help`（シェル組み込みコマンド）

`cd` や `export` のような**シェルの組み込みコマンド**には man ページがありません。
これらは `help` で調べます。

```bash
$ help cd                           # cd はシェル組み込みなので help で調べる
cd: cd [-L|[-P [-e]] [-@]] [dir]
    Change the shell working directory.

$ type cd                           # 組み込みかどうかを確認する
cd is a shell builtin

$ type ls                           # ls は外部コマンド（man がある）
ls is aliased to `ls --color=auto'
```

| 種類 | 調べ方 | 例 |
|:--|:--|:--|
| 外部コマンド | `man` | `ls` `grep` `find` |
| シェル組み込み | `help` | `cd` `export` `set` `history` |

## man ページの実体と場所

man ページはファイルとして置かれています。場所は `MANPATH` または設定ファイルで決まります。

```bash
$ man -w ls                         # ls の man ページの実体の場所を表示
/usr/share/man/man1/ls.1.gz

$ man -w 5 crontab                  # セクション5の crontab の場所
/usr/share/man/man5/crontab.5.gz

$ ls /usr/share/man/                # セクションごとにディレクトリが分かれている
man1  man2  man3  man4  man5  man6  man7  man8

$ echo $MANPATH                     # 検索パス（空なら設定ファイルの既定値が使われる）
```

**補足 … 日本語 man ページ**

ディストリによっては日本語の man ページをパッケージで追加できます。
ただし**内容が古いことが多い**ため、正確さが必要な場面では英語版を確認するのが安全です。

```bash
$ sudo dnf install man-pages-ja     # RHEL系で日本語 man をインストール
$ sudo apt install manpages-ja      # Debian系

$ man ls                            # LANG が ja_JP なら日本語版が表示される
$ LANG=C man ls                     # このコマンドの間だけ英語版を表示する
```
