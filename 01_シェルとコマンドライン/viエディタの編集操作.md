## バッファという考え方

**vi の編集コマンドを理解する鍵は「バッファ」**です。

**バッファとは、切り取ったり写したりした内容を一時的に置いておく場所**です。
Windows の「クリップボード」にあたります。

```text
   ファイル本文             バッファ
  ┌────────────┐            ┌──────────┐
  │ one        │  yy(写す)  │          │
  │ two        │ ---------> │   two    │
  │ three      │            │          │
  └────────────┘  p(貼る)   └──────────┘

  yy / dd でバッファへ入れ、p / P で本文へ戻す
```

**ここが重要です。** vi では **`dd`（削除）もバッファに入ります**。

| コマンド | 本文から | バッファへ |
|:--|:--|:--|
| **`yy`**（コピー） | **消えない** | **入る** |
| **`dd`**（削除） | **消える** | **入る** |

つまり **vi の「削除」は Windows でいう「切り取り」** です。
**消したものは `p` で貼り戻せます**。これを知っていると、
`dd` してから `p` で移動させる、という使い方ができます。

**補足** … `y` は **yank（引き抜く）**、`d` は **delete**、`p` は **paste** の頭文字です。
コマンドの意味は英単語で覚えると忘れません。

## 編集コマンドの一覧

**ファイルの編集に関する主な vi コマンド**です。すべて**コマンドモード**で使います。

| コマンド | 説明 |
|:--|:--|
| **`yy`** / **`Y`** | **カーソル位置の行をバッファにコピー** |
| **`yw`** | **カーソル位置の単語をバッファにコピー** |
| **`dd`** | **カーソル位置の行を削除し、バッファにコピー** |
| **`dw`** | **カーソル位置の単語を削除し、バッファにコピー** |
| **`x`** | **カーソル位置の文字を削除し、バッファにコピー** |
| **`X`** | **カーソル位置の左の文字を削除し、バッファにコピー** |
| **`p`** | **バッファの内容を挿入**（文字や単語はカーソルの右、行はカーソルの下に挿入） |
| **`P`** | **バッファの内容を挿入**（文字や単語はカーソルの左、行はカーソルの上に挿入） |
| **`u`** | **元に戻す**（直前の編集をとりやめる） |
| **`.`**（ピリオド） | **繰り返す**（直前の編集を再実行する） |

**`yy` と `Y` は同じ意味**です。どちらも「行をコピー」します。

## コピーする

**`yy` で 1 行、`yw` で 1 単語**をバッファに写します。**本文は変わりません。**

```text
   元の状態              yy を押す              バッファ
  one   ← カーソル      one                    one
  two                   two
  three                 three
                        （本文は変化なし）
```

```bash
$ vi t.txt                            # one / two / three / four の4行を開く
                                      # gg で1行目へ → 3yyP を実行した結果が次
```

```text
one
two
three
one
two
three
four
```

**`3yy` で 3 行をまとめてバッファに入れ、`P` でカーソルの上に貼った**結果です。
元の `one two three four` は残り、その上に `one two three` が挿入されています。

**単語のコピーは `yw`** です。

```bash
$ vi t.txt                            # alpha beta の1行を開く
                                      # gg で行頭へ → ywP を実行した結果が次
```

```text
alpha alpha beta
```

**`yw` が写したのは `alpha ` （末尾の空白を含む）** で、
`P` でカーソルの左に貼ったので `alpha alpha beta` になりました。

## 削除する

### xとXの違い

**どちらも 1 文字削除ですが、消える場所が逆**です。

```text
   a b [c] d e f      ← カーソルは c の上

     x を押す  →  a b d e f      ← カーソル位置の「c」が消える
     X を押す  →  a c d e f      ← カーソルの左の「b」が消える
```

| コマンド | 消えるもの | 覚え方 |
|:--|:--|:--|
| **`x`**（小文字） | **カーソル位置の文字** | **Delete キー**と同じ感覚 |
| **`X`**（大文字） | **カーソルの左の文字** | **Backspace キー**と同じ感覚 |

```bash
$ vi t.txt                            # abcdef の1行を開く
                                      # gg → ll でカーソルを3文字目(c)へ → x
```

```text
abdef                                 ← c が消えた
```

```bash
$ vi t.txt                            # abcdef の1行を開き直す
                                      # gg → ll でカーソルを3文字目(c)へ → X
```

```text
acdef                                 ← 左隣の b が消えた
```

**補足** … `x` も `X` も削除した文字はバッファに入りますが、
**1 文字を貼り付ける場面はほとんど無い**ので、実質は「削除」として使われます。

### ddとdwの違い

| コマンド | 消えるもの |
|:--|:--|
| **`dd`** | **カーソルのある行まるごと** |
| **`dw`** | **カーソル位置から単語の終わりまで**（次の単語の先頭の直前まで） |

```bash
$ vi t.txt                            # alpha beta gamma の1行を開く
                                      # gg で行頭へ → dw を実行した結果が次
```

```text
beta gamma                            ← alpha と後ろの空白が消えた
```

```bash
$ vi t.txt                            # one / two / three の3行を開く
                                      # gg → j で2行目へ → dd を実行した結果が次
```

```text
one
three                                 ← two の行が消えた
```

**`dw` は「カーソル位置から」**であって、「単語まるごと」ではありません。
単語の途中にカーソルがあると、**そこから右側だけ**が消えます。

```text
   al[p]ha beta       ← カーソルが p の上

     dw を押す  →  albeta            ← p から単語末＋空白までが消える
```

**単語をまるごと消したいときは `b` で単語の先頭へ戻ってから `dw`**、
または `daw`（vim の機能）を使います。

## 貼り付ける

### pとPの違い

**`p` と `P` は「どちら側に貼るか」が違います。**
さらに **バッファの中身が「行」か「文字・単語」かで動きが変わります**。

| コマンド | バッファが**行**のとき | バッファが**文字・単語**のとき |
|:--|:--|:--|
| **`p`**（小文字） | **カーソルの行の下に挿入** | **カーソルの右に挿入** |
| **`P`**（大文字） | **カーソルの行の上に挿入** | **カーソルの左に挿入** |

**大文字が「上・左」、小文字が「下・右」**と覚えます。

```bash
$ vi t.txt                            # one / two / three / four を開く
                                      # gg → 3yyp（小文字のp）を実行した結果が次
```

```text
one
one
two
three
two
three
four
```

**`3yy` で `one two three` をコピーし、`p` でカーソル行（1行目）の下に挿入**されました。
`P` のとき（前掲）とは挿入位置が 1 行分ずれています。

```text
  3yyP →  one two three | one two three four   ← 元の1行目の「上」
  3yyp →  one | one two three | two three four ← 元の1行目の「下」
```

**補足 … バッファは上書きされます**

**`yy` や `dd` を実行するたびにバッファの中身は置き換わります。**
「1 行目をコピー → 別の行を削除 → 貼り付け」とやると、
**貼り付けられるのは削除した行**です。`dd` もバッファに入るためです。

## 取り消しと繰り返し

| コマンド | 説明 |
|:--|:--|
| **`u`** | **元に戻す**（直前の編集をとりやめる） |
| **`.`**（ピリオド） | **繰り返す**（直前の編集を再実行する） |
| `Ctrl+r` | やり直す（`u` を取り消す。vim の機能） |
| `U` | カーソルのある行への変更をまとめて取り消す |

**`u` は事故からの復帰手段です。**
コマンドモードのつもりが入力モードだった、`dd` を押しすぎた、という場面で
**まず `Esc`、次に `u`** を押してください。

> **オリジナルの vi では `u` は 1 回しか戻せません。**
> 何回も戻せるのは vim の拡張です。**試験では「1 回」が前提**と考えてください。

**`.`（ピリオド）は直前の編集の繰り返し**です。

```bash
$ vi t.txt                            # abcdef の1行を開く
                                      # gg → x（aが消える）→ .（直前のxを繰り返す）
```

```text
cdef                                  ← a と b の2文字が消えた
```

**`.` が繰り返すのは「編集」だけ**です。カーソル移動は繰り返しません。
そのため「移動して `.`、移動して `.`」という使い方になります。

## 数字を前に付けて繰り返す

**vi コマンドの直前に数字を付けると、その回数分 vi コマンドが繰り返されます。**

| 書き方 | 意味 |
|:--|:--|
| **`3dd`** | **3 行削除する** |
| **`3yy`** | **3 行コピーする** |
| **`5x`** | **5 文字削除する** |
| `10j` | 10 行下へ移動する |

**この仕組みと `p` / `P` を組み合わせたのが `3yyP` のような形**です。

```text
   3 yy P
   │  │  │
   │  │  └─ カーソルの上に貼る
   │  └──── 行をコピー
   └─────── 3回ぶん（＝3行）
```

**`3YP` も同じ意味**です（`Y` は `yy` と同義なので）。

**補足 … `3yp` は動きません**

`y` は単独では「コピーする対象」が決まらないため、**`y` だけでは何も起きません**。
`yy`（行）や `yw`（単語）のように、**何をコピーするかまで指定する必要**があります。

| 書き方 | 動くか | 理由 |
|:--|:-:|:--|
| **`3yyP`** | **○** | `yy` で行を指定している |
| **`3YP`** | **○** | `Y` は `yy` と同じ |
| `3yp` | **✕** | `y` だけでは対象が決まらない |

## コマンドの組み立て方

**vi のコマンドは「回数」「動作」「対象」の3つを組み合わせた文法**になっています。
これが分かると、覚えるべきものが一気に減ります。

```text
   [回数]  [動作]  [対象]

      3      d       d     →  3行削除
      3      d       w     →  3単語削除
      5      y       y     →  5行コピー
             d       $     →  カーソルから行末まで削除
             y       G     →  カーソルから最終行までコピー
```

| 動作 | 意味 |
|:--|:--|
| **`d`** | delete（削除） |
| **`y`** | yank（コピー） |
| `c` | change（削除して入力モードへ） |

| 対象 | 意味 |
|:--|:--|
| **同じ文字を重ねる**（`dd` `yy`） | **行まるごと** |
| **`w`** | **単語** |
| `$` | 行末まで |
| `0` | 行頭まで |
| `G` | 最終行まで |
| `gg` | 先頭行まで |

**「対象」の部分はカーソル移動コマンドと同じ**です
（[viエディタの基本とモード](./viエディタの基本とモード.md) の「カーソルを動かす」）。
つまり**移動コマンドを覚えれば、そのまま削除・コピーの範囲指定に使えます**。

## 実務でよく使う組み合わせ

| やりたいこと | コマンド |
|:--|:--|
| **設定行を 1 行コメントアウトする** | `I` → `#` → `Esc` |
| **設定行を 1 行消す** | **`dd`** |
| **似た設定行を複製して書き換える** | **`yy`** → `p` → 書き換え |
| **行の順番を入れ替える** | **`dd`** → 移動 → **`p`** |
| **行末の余分な文字を消す** | `$` → `x` を必要なだけ |
| **カーソルから行末まで消す** | `d$`（または `D`） |
| **やらかしたので戻す** | **`Esc`** → **`u`** |

**「dd → 移動 → p」で行の移動ができる**のは、
`dd` がバッファに入るからです。切り取り＆貼り付けと同じ感覚で使えます。

**補足 … コメントアウトは `I` が速いです**

設定ファイルで行頭に `#` を足す作業は、**`I` で行頭に飛んで `#` を打ち、`Esc`** の3手です。
`0` で行頭へ移動してから `i` を押す必要はありません。
**複数行なら `Esc` のあとに `j` と `.` を交互に押す**と、同じ編集を繰り返せます。
