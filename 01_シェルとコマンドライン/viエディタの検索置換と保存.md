## コロンで始まるコマンド

**コマンドモードで `:` を押すと、画面のいちばん下に `:` が出て、コマンドの入力待ちになります。**

```text
…（略）
nscd:x:28:28:NSCD Daemon:/:/sbin/nologin
:                                          ← ここに打ち込む
```

**この `:` で始まるコマンドは「ex コマンド」**と呼ばれます。
`vi` の前身である `ex` というラインエディタから受け継いだ機能で、
**保存・終了・置換・設定**はすべてここで行います。

| 打ち込み先 | 例 | 特徴 |
|:--|:--|:--|
| **コマンドモードで直接** | `dd` `yy` `x` `G` | **押した瞬間に実行**される |
| **`:` のあと** | `:wq` `:%s/a/b/g` `:set nu` | **`Enter` を押すと実行**される |

**`:` を打ってから気が変わったら `Esc`** を押せば取り消せます。

## 文字列を検索する

### 検索コマンドの一覧

**以下は文字列の検索に関する主な vi コマンド**です。

| コマンド | 説明 |
|:--|:--|
| **`/文字列`** | **指定した文字列を、カーソル位置からファイルの末尾（前方・進行方向）に向かって検索** |
| **`?文字列`** | **指定した文字列を、カーソル位置からファイルの先頭（後方・逆方向）に向かって検索** |
| **`n`** | **次を検索** |
| **`N`** | **次を検索（逆方向）** |

**`/` と `?` は検索する文字列の「前」に指定します。**
`sbin/` や `sbin?` のように後ろに書いても検索にはなりません。

### 前方検索と後方検索

**「前方」「後方」という言葉が紛らわしい**ので、方向を図にします。

```text
    ファイルの先頭
         ▲
         │  ?文字列   … 後方検索（逆方向）。上に向かって探す
         │
   ━━━ カーソル ━━━
         │
         │  /文字列   … 前方検索（進行方向）。下に向かって探す
         ▼
    ファイルの末尾
```

| 覚え方 | |
|:--|:--|
| **`/`** | そのまま押すのが**基本の検索**。**下（末尾）へ** |
| **`?`** | `/` に **Shift** を足したキー。「ひと手間かけた逆向き」で**上（先頭）へ** |

**例文** … `/etc/passwd` の中の `sbin` を探します。

```text
root:x:0:0:root:/root:/bin/bash
bin:x:1:1:bin:/bin:/sbin/nologin
daemon:x:2:2:daemon:/sbin:/sbin/nologin
…（略）
/sbin                                 ← ここに打ち込んで Enter
```

**1 行目にカーソルがある状態で `/sbin` を実行すると、
最初に見つかった `sbin` である 2 行目の `/sbin/nologin` にカーソルが移動**します
（実測：2 行 21 桁目）。

逆に、**最終行（3 行目）の先頭にカーソルがある状態で `?sbin` を実行すると、
上に向かって探して 2 行目の `sbin` が見つかります**（実測：2 行 21 桁目）。
3 行目にも `sbin` は 2 つありますが、**どちらもカーソルより後ろ**にあるため、
後方検索では飛ばされます。**「カーソルより前だけを探す」のが `?`** です。

### 次の候補へ移動する

**検索したあと、同じ文字列の次の候補へ移るには `n` を押します。**

| 直前の検索 | **`n`** | **`N`** |
|:--|:--|:--|
| **`/文字列`**（下方向） | **下方向へ次を探す** | **上方向へ探す** |
| **`?文字列`**（上方向） | **上方向へ次を探す** | **下方向へ探す** |

**`n` は「直前の検索と同じ方向」、`N` は「逆方向」**です。
`n` が常に下、というわけではない点に注意してください。

```text
   /sbin を実行  →  2行目21桁  （最初に見つかった sbin）
   n を押す      →  3行目22桁  （その次の sbin）
   N を押す      →  2行目21桁  （1つ戻る）
```

**補足 … `m` は検索コマンドではありません**

`m` は**マーク**を付けるコマンドです（`ma` でいまの位置に `a` という印を付ける）。
検索の続きを見たいときは `n`、と覚えてください。

**補足 … 検索には正規表現が使えます**

```text
/^root        → root で始まる行を探す
/nologin$     → nologin で終わる行を探す
/bin.*sh      → bin のあとに sh が続く行を探す
```

記号の意味は [正規表現の基礎](../02_テキスト処理と正規表現/正規表現の基礎.md) にまとめています。

## 文字列を置換する

### 置換の書式

**ファイル全体の文字列を置換するには、コマンドモードで次の vi コマンドを実行します。**

```text
:%s/文字列1/文字列2/g
```

**5 つの部品**でできています。

```text
   :  %   s  /ping-t/hoge/  g
   │  │   │        │        │
   │  │   │        │        └─ 範囲内のすべての文字列1を置換対象とする
   │  │   │        └────────── 置換前 / 置換後
   │  │   └─────────────────── substitute（置換）
   │  └─────────────────────── ファイル全体の行を対象にする
   └────────────────────────── ex コマンドの入り口
```

| 部品 | 意味 |
|:--|:--|
| **`%`** | **ファイル全体の行** |
| **`s`** | **置換**（substitute） |
| **`g`** | **範囲内のすべての文字列1を置換対象とする**（global） |

```bash
$ vi t.txt                            # 「ping-t is ping-t」「ping-t only」の2行を開く
                                      # :%s/ping-t/hoge/g を実行した結果が次
```

```text
hoge is hoge
hoge only
```

### gを付けないとどうなるか

**`g` を付けないと、各行の最初に見つかった文字列1のみが置換対象**になります。

```bash
$ vi t.txt                            # 同じ2行を開き直す
                                      # :%s/ping-t/hoge/ を実行した結果が次
```

```text
hoge is ping-t                        ← 1行目の2つ目が置換されていない
hoge only
```

**「行ごとに 1 回だけ」が `g` 無しの動き**です。
「ファイル全体で 1 回だけ」ではない点に注意してください。

**よくある誤答の形**

| 書き方 | 動くか | 何が違うか |
|:--|:--|:--|
| **`:%s/ping-t/hoge/g`** | **○** | 正しい形 |
| `:%s/ping-t/hoge/` | △ | 動くが**各行の最初の1つだけ** |
| `:/ping-t/hoge/g` | ✕ | **`s` が無い**。置換コマンドになっていない |
| `:'s/ping-t/hoge/g'` | ✕ | **クォートは不要**。シェルではないので付けてはいけない |

### 範囲を指定した置換

**`%` の部分を数字にすると、置換する行の範囲を絞れます。**

| 書き方 | 対象 |
|:--|:--|
| **`:%s/A/B/g`** | **ファイル全体** |
| **`:s/A/B/g`** | **カーソルのある行だけ** |
| `:1,10s/A/B/g` | **1 行目から 10 行目まで** |
| `:.,$s/A/B/g` | **カーソル行から最終行まで**（`.` が現在行、`$` が最終行） |
| `:1,$s/A/B/g` | 1 行目から最終行まで（＝ `%` と同じ） |

**末尾に `c` を足すと 1 件ずつ確認できます。**

```text
:%s/ping-t/hoge/gc
```

`y`（置換する）/ `n`（飛ばす）/ `a`（以降すべて）/ `q`（やめる）で答えます。
**本番の設定ファイルでは `gc` を使う**のが安全です。

**補足 … 置換したい文字列に `/` が含まれるとき**

パスを置換するときなど、区切り文字の `/` が中身に出てくると読みにくくなります。
**区切り文字は `/` 以外でも構いません。**

```text
:%s/\/etc\/old/\/etc\/new/g      ← 読みにくい
:%s#/etc/old#/etc/new#g          ← # を区切りにすると読みやすい
```

## 保存と終了

### 保存と終了のコマンド一覧

**以下は vi エディタの終了とファイルの保存に関する主な vi コマンド**です。

| コマンド | 説明 |
|:--|:--|
| **`:q`** | **vi を終了**。ただし、内容が変更されている場合は、警告が出て終了できない |
| **`:q!`** | **vi を強制終了**。内容が変更されている場合でも**保存せず終了** |
| **`:w`** | **編集内容を保存** |
| **`:w ファイル名`** | **編集内容を指定したファイルに保存**（名前を付けて保存） |
| **`:wq`** / **`:x`** / **`ZZ`** | **編集内容を保存し vi を終了** |
| **`:wq!`** | **編集内容を強制保存し vi を終了**。読み取り専用のファイルでも強制的に保存して終了（強制保存に失敗したら vi は終了しない） |

**`q` は quit（終了）、`w` は write（書き込み）、`!` は強制**の意味です。
この 3 つの組み合わせだと分かれば、表を丸暗記する必要はありません。

```text
        保存する   終了する   強制
  :w       ○          —        —
  :q       —          ○        —
  :wq      ○          ○        —
  :q!      —          ○        ○（変更を捨てる）
  :wq!     ○          ○        ○（読み取り専用でも書く）
```

**`ZZ` だけコロンが要りません。** コマンドモードで大文字の `Z` を 2 回押します。
`:wq` と同じ動きですが、**`:x` と `ZZ` は内容に変更が無いときファイルを書き換えません**
（タイムスタンプが更新されない）という細かい違いがあります。

| | `:wq` | `:x` / `ZZ` |
|:--|:--|:--|
| 変更があるとき | 保存して終了 | 保存して終了 |
| **変更が無いとき** | **保存する**（更新日時が変わる） | **保存しない**（更新日時が変わらない） |

### 変更があるのに終了しようとしたとき

**`:q` は、変更が保存されていないと拒否されます。**

```text
E37: No write since last change (add ! to override)
```

このメッセージが出たときの選択肢は 3 つです。

| どうしたいか | コマンド |
|:--|:--|
| **変更を保存して閉じたい** | **`:wq`** |
| **変更を捨てて閉じたい** | **`:q!`** |
| 保存だけして編集を続けたい | `:w` |

**「設定ファイルを開いたが、間違えて何か打ってしまった」ときは `:q!`** です。
実測でも、`:q` では中身が書き換わらず（終了が拒否される）、
`:q!` では編集内容が捨てられてファイルは元のままでした。

### 読み取り専用ファイルを保存する

**`vi -R` で開いた場合や、書き込み権限が無いファイルは `:w` で保存できません。**

```text
E45: 'readonly' option is set (add ! to override)
```

**`:w!` または `:wq!` で強制保存を試みます。**
ただし**ファイルシステム上の権限が無ければ、`!` を付けても書けません**。

```text
"/etc/httpd/conf/httpd.conf" E212: Can't open file for writing
```

**この場合 vi は終了しません。** 編集内容は失われないので、次のどちらかで逃げます。

```text
:w /tmp/mycopy.conf      ← 書ける場所に名前を付けて保存する
:q!                      ← 諦めて捨てる
```

**root 権限が必要なファイルは、最初から `sudo vi` で開いてください。**

## 別ファイルを読み込む

**指定したファイルの内容をカレント行の後に読み込んで挿入するには、
コマンドモードで次の vi コマンドを実行します。**

```text
:r ファイル名
```

**`r` は read の頭文字**です。

```bash
$ vi main.txt                         # AAA / BBB の2行を開く
                                      # 1行目にカーソルを置いて :r test.txt を実行
```

```text
AAA
inserted1                             ← 読み込まれた内容
inserted2
BBB
```

**挿入されるのは「カーソル行の次」**です。1 行目にカーソルがあれば 2 行目以降に入ります。

**先頭に入れたいときは行番号 `0` を指定します。**

```bash
$ vi main.txt                         # AAA / BBB の2行を開き直す
                                      # :0r test.txt を実行した結果が次
```

```text
inserted1
inserted2
AAA
BBB
```

**よくある間違い**

| 書き方 | 意味 |
|:--|:--|
| **`:r test.txt`** | **ファイルを読み込んで挿入する**（正しい） |
| `/test.txt` | 文字列 `test.txt` を**検索**する |
| `?test.txt` | 文字列 `test.txt` を**逆方向に検索**する |
| `: test.txt` | 無効（`r` が無い） |
| `:!r test.txt` | **シェルコマンドの実行**になる（`:!コマンド` の形）。`r` というシェルコマンドは無いので `shell returned 127` で終わる |

**補足 … コマンドの実行結果を読み込むこともできます**

```text
:r !date                 ← date コマンドの結果を挿入する
:r !ls /etc              ← ls の結果を挿入する
```

**手順書やログに、実行結果をそのまま貼り込むとき**に使えます。

## viを終了せずにコマンドを実行する

**編集中に「あのファイル名なんだっけ」となったとき、vi を閉じる必要はありません。**

```text
:!コマンド
```

**`!` の後ろに書いたものが、そのままシェルに渡されて実行されます。**

```bash
$ vi vt.txt                           # 編集中のファイルを開いている
                                      # ここで :!ls を実行すると次が出る
```

```text
:!ls
vt.txt

Press ENTER or type command to continue
```

**結果が画面に出たあと、`Enter` を押すと vi の画面に戻ります。**
**編集中の内容は失われません。**

| 書き方 | 何が起きるか |
|:--|:--|
| **`:!ls`** | **シェルで `ls` を実行する**（vi は開いたまま） |
| **`:!コマンド`** | **任意のシェルコマンドを実行する** |
| `:r !ls` | **`ls` の結果を本文に読み込む**（前の節） |
| `:sh` | **シェルを起動する**。`exit` で vi に戻る |
| `/ls` | 文字列 `ls` を**検索**する（コマンド実行ではない） |
| `?ls` | 文字列 `ls` を**逆方向に検索**する |
| `:ls` | **vi の「バッファ一覧」コマンド**。シェルの `ls` ではない |
| `!:ls` | **無効**（`!` と `:` の順番が逆） |

**`!` の位置が要**です。**`:` の直後に `!`** と覚えてください。

```text
   :  !  l  s
   │  │  └──┴─ 実行したいシェルコマンド
   │  └─────── 「シェルに渡す」という合図
   └────────── コマンドモードへの入口
```

**よく使う場面**

```text
:!ls                     ← 読み込みたいファイル名を確かめる
:!date                   ← いまの時刻を確かめる
:!diff % %.bak           ← 編集中のファイルとバックアップを比べる（% は編集中のファイル名）
:!bash -n %              ← 編集中のシェルスクリプトを構文チェックする
```

**`%` は「編集中のファイル名」に展開されます。**
**保存してから実行しないと、ディスク上の古い内容が対象**になる点に注意してください。

## viの設定を変える

### 設定コマンドの一覧

**以下は vi の設定に関する主な vi コマンド**です。

| コマンド | 説明 |
|:--|:--|
| **`:set nu`** / **`:set number`** | **行番号を表示** |
| **`:set nonu`** / **`:set nonumber`** | **行番号を表示しない** |
| **`:set ts=タブ幅`** / **`:set tabstop=タブ幅`** | **タブ幅を数値で指定** |

**`nu` は `number` の省略形**です。どちらで書いても同じで、
**打ち消したいときは頭に `no` を付ける**（`nonu` / `nonumber`）という規則になっています。

```text
   set   nu           →  行番号を表示する
   set no nu          →  行番号を表示しない
         └┬┘
       number の省略形
```

**実測で確認した結果**

| 打ったコマンド | `number` の値 |
|:--|:-:|
| `:set nu` | **1（有効）** |
| `:set number` | **1（有効）** |
| `:set nonu` | **0（無効）** |
| `:set nonumber` | **0（無効）** |

| 打ったコマンド | `tabstop` の値 |
|:--|:-:|
| `:set ts=10` | **10** |
| `:set tabstop=10` | **10** |

**間違えやすい書き方と、実際に出るエラー**

| 書き方 | 結果 |
|:--|:--|
| **`:set ts 10`** | **`E518: Unknown option: 10`**（`ts` と `10` が別のオプション名として読まれ、`tabstop` は 8 のまま） |
| **`:set tab=10`** | **`E518: Unknown option: tab=10`**（`tab` というオプションは無い） |
| **`:set number=10`** | **`E474: Invalid argument: number=10`**（`number` は ON/OFF で、値は取らない） |
| **`:nonu`** | **`E492: Not an editor command: nonu`**（`set` が無い） |

**`set` を忘れるのがいちばん多い間違い**です。`:nonu` だけでは動きません。

**そのほかよく使う設定**

| コマンド | 意味 |
|:--|:--|
| `:set list` / `:set nolist` | **タブや行末を記号で表示する**（`^I` と `$`） |
| `:set ic` / `:set noic` | 検索で大文字小文字を区別しない（ignorecase） |
| `:set hls` / `:set nohls` | 検索結果を**ハイライト**する（highlight search） |
| `:set ai` / `:set noai` | 自動インデント（autoindent） |
| `:set paste` / `:set nopaste` | **貼り付けモード**（自動インデントを一時的に切る） |
| `:set` | **既定から変更されている設定の一覧**を表示する |
| `:set all` | すべての設定を表示する |

**補足 … 貼り付けが階段状に崩れたら `:set paste`**

端末に設定ファイルを貼り付けると、**自動インデントが重なって階段状になる**ことがあります。
`:set paste` で入力モードに入ってから貼り、終わったら `:set nopaste` で戻します。
**これを知らないと、貼り付けのたびにインデントを手で直すことになります。**

### 設定を永続化する

**`:set` で変えた設定は、vi を終了すると消えます。**
毎回使いたい設定は、**ホームディレクトリの `~/.exrc`（vi）または `~/.vimrc`（vim）** に書きます。

```bash
$ vi ~/.vimrc                         # 設定ファイルを作る（無ければ新規作成される）
```

```text
set number
set tabstop=4
set expandtab
set hlsearch
```

**`:` は書きません。** 設定ファイルの中では `set` から始めます。

**補足 … 共用サーバでは設定を変えないでください**

`~/.vimrc` は自分だけのものですが、**`/etc/vimrc` は全ユーザに影響します**。
運用手順書が「素の vi」を前提に書かれていることも多いので、
**作業用アカウント以外では設定を足さない**のが無難です。
