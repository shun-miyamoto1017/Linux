## ARPとは何か

**ネットワーク通信は、レイヤ（階層）構造を成しているプロトコルが、
それぞれ独立した役割を果たすことによって実現されています。**

```text
  アプリケーション層   HTTP など … 意味のある情報をやりとりする
        ▼
  インターネット層     IP        … 離れた場所にあるホストと通信する
        ▼
  リンク層             Ethernet  … 直接つながっている機器どうしで転送する
                                    ここで使うアドレスが MAC アドレス
```

**普段意識するのは IP アドレスを使った通信のレベルまで**ですが、
**そのような便利な通信ができるのは、より下位のレイヤが
物理的なデバイス間でのデータ転送を制御してくれているから**です。

**MAC アドレスは、それぞれの物理的なデバイスに一意に（被らないように）書き込まれているアドレス**です。
**直接つながっている（同じネットワーク内の）デバイス間では、この MAC アドレスを使って通信**します。

**ところが、ユーザは IP アドレスで通信先を指定してきます。**
**そこで IP アドレスから MAC アドレスを求める必要が出てきます。**

**その方法（プロトコル）が ARP（Address Resolution Protocol）**です。

```text
  ① 「192.168.11.3 の人、MAC アドレスを教えて」
        ▼ ネットワーク内に一斉送信（ブロードキャスト）
  ② 該当するホストだけが「私です、MAC は 00:0d:0b:e6:95:e3 です」と返す
        ▼
  ③ 分かった対応を手元にメモしておく（ARP キャッシュ）
```

**MAC アドレスを知らない相手と通信するには、全体に問いかければいい**——
というのが ARP の理屈です。

## ARPキャッシュ

**判明した IP と MAC の対応関係は、ARP キャッシュというテーブルとしてシステム内に保持されます。**
**このキャッシュがあるので、次からはいちいちブロードキャストしなくても済みます。**

**`arp` コマンドは、この ARP キャッシュを操作・表示するためのコマンド**です。

```text
  arp が触るのは  「キャッシュ（メモ帳）」
  ARP が行うのは  「ブロードキャストでの問い合わせ」
        ▲ コマンドとプロトコルは別物。名前が同じなので混ざりやすい
```

**キャッシュは自動で作られ、時間が経つと消えます。**
手で書いた（静的な）エントリは消えません。

## arp のオプション

```text
arp [オプション]
```

| オプション | 意味 | 分類 |
|:--|:--|:--|
| **`-i`** | **続けて表示対象インタフェースを指定する** | **表示** |
| **`-a`** | **続けて表示対象のホスト名を指定する** | **表示** |
| **`-n`** | **逆引きを行わず、IP アドレスのまま表示する** | **表示** |
| **`-d`** | **続けて削除対象のホスト名を指定する** | **削除** |
| **`-s`** | **続けて IP と MAC アドレスの対応を指定し、キャッシュに追加する** | **追加** |
| **`-f`** | **続けてファイルを指定し、その内容をキャッシュに追加する** | **追加** |

**覚えるべきオプションは少し多い**ですが、
**表示・追加・削除で操作が大きく分かれている**ので、そこで区切ると整理できます。

```text
  表示   -i（インタフェース）  -a（ホスト）  -n（名前を引かない）
  追加   -s（引数で直接）      -f（ファイルから）
  削除   -d（ホスト）
```

> **実機との差**：`net-tools 2.10` の `arp --help` では
> **`-a` は「BSD 形式で表示する」オプション**として説明されており、
> **ホスト名は位置引数**として `arp [-vn] [<HW>] [-i <if>] [-a] [<hostname>]` の形で受け取ります。
> そのため **`arp -a 192.168.11.10` は「BSD 形式で、そのホストだけを表示する」**という動きになり、
> **結果としては Ping-t の説明どおり**になります。
> **Linux 形式（表形式）で 1 ホストだけ見たいときは `arp -e 192.168.11.10`** か、
> 単に **`arp 192.168.11.10`** とします（サンドボックスで確認）。

## 表示する

**そのまま実行するとキャッシュ全体が出ます。**

```bash
$ arp                                  # ARP キャッシュを一覧表示する（実機で確認）
Address                  HWtype  HWaddress           Flags Mask            Iface
192.0.2.1                ether   02:fc:00:00:00:05   C                     eth0
```

**IP のまま表示する `-n`**

**逆引き（IP アドレスからホスト名を調べること）を行わない**ので、
**`Address` 欄に IP アドレスがそのまま出ます。**

```bash
$ arp -n                               # 名前を引かず IP のまま表示する
Address                  HWtype  HWaddress           Flags Mask            Iface
192.0.2.1                ether   02:fc:00:00:00:05   C                     eth0
```

**「ホスト名で表示されてしまうので IP で見たい」への答え**

| 選択肢 | 正誤 | 理由 |
|:--|:-:|:--|
| **`arp` に `-n` を指定する** | **○** | **逆引きをやめれば IP のまま出る** |
| `/etc/hosts` を編集する | ✕ | **そもそも名前を引かせないのが目的**。逆向きの対処 |
| `/etc/networks` を編集する | ✕ | **ネットワーク名の設定ファイル**。ホスト名とは無関係 |
| `arp` ではなく `ifconfig eth0` を実行する | ✕ | **`ifconfig` は ARP キャッシュを扱えない** |

**対象を絞る**

```bash
$ arp -a 192.168.11.10                 # 特定のホストだけ表示する
$ arp -i eth1                          # eth1 に関するエントリだけ表示する
```

| 問われ方 | 答え | 誤答しやすいもの |
|:--|:--|:--|
| **IP アドレス 192.168.11.10 に関するエントリだけ** | **`arp -a 192.168.11.10`** | **`arp -i 192.168.11.10`**（`-i` はインタフェース指定） |
| **インタフェース eth1 に関するエントリだけ** | **`arp -i eth1`** | **`arp -a eth1`**（`-a` はホスト指定） |

> **`-i` は interface、`-a` は address（ホスト）**——
> **頭文字で覚える**と取り違えません。

## 追加する

**`-s` は引数で直接、`-f` はファイルから**

| オプション | 書き方 | 対応関係をどこに書くか |
|:--|:--|:--|
| **`-s`** | **`arp -s ホスト MACアドレス`** | **コマンドの引数に直接書く** |
| **`-f`** | **`arp -f [ファイル名]`** | **あらかじめファイルに書いておく** |

```bash
$ sudo arp -s 192.168.1.100 aa:bb:cc:dd:ee:ff   # 引数で直接指定して追加する
$ sudo arp -f                                    # /etc/ethers から読み込んで追加する
```

**`-f` はファイル名を省略できる**

**ファイル名の指定を省略した場合は、既定で `/etc/ethers` が指定されたものとして扱われます。**
**このデフォルトファイルに設定を書く場合は、`-f` はファイル名を指定することなく単体で使えます。**

```bash
$ cat /etc/ethers                      # 1行に「IPアドレス MACアドレス」を書く
192.0.2.77 aa:bb:cc:00:00:77
$ sudo arp -f                          # ファイル名を省略すると /etc/ethers を読む
$ arp -n | grep 192.0.2.77             # 追加されている（実機で確認）
192.0.2.77               ether   aa:bb:cc:00:00:77   CM                    eth0
```

**`-a` と `-i` を「追加のオプション」と答えないこと**

「ARP キャッシュテーブルに対応関係を追加したい」という設問では、
**`-a` と `-i` は現在のキャッシュ内容を表示することに関連したオプション**なので誤りです。
**正解は `-s` と `-f`** の 2 つです。

## 削除する

```bash
$ sudo arp -d 192.168.11.10            # 指定したホストのエントリを削除する
```

| 選択肢 | 正誤 | 理由 |
|:--|:-:|:--|
| **`-d`** | **○** | **delete。続けて削除対象のホスト名を指定する** |
| `-f` | ✕ | **ファイルから追加する**オプション |
| `-n` | ✕ | **逆引きを行わない**表示オプション |
| `-r` | ✕ | **そのようなオプションは無い** |

> **`-a` と `-d` の値は、ホスト名（`host1.example.com` など）と
> IP アドレス（`192.168.11.10` など）のどちらでも指定できます。**

## ip neigh との違い

**ARP キャッシュの内容は `ip neigh show` でも確認できます。**

```bash
$ ip neigh show                        # ip コマンド側の書き方（実機で確認）
192.0.2.1 dev eth0 lladdr 02:fc:00:00:00:05 REACHABLE
```

| | **`arp`** | **`ip neigh`** |
|:--|:--|:--|
| **所属** | **net-tools（古い）** | **iproute2（新しい）** |
| **出力形式** | **表形式** | **1 行 1 エントリ** |
| **状態の表示** | **`Flags` 欄（`C` / `CM`）** | **`REACHABLE` など状態を明示する** |
| **IPv6** | 扱えない | **扱える** |

**`arp` コマンドと異なり、`ip` コマンドは `REACHABLE`（到達可能）などのホストの状態も表示します。**

| 状態 | 意味 |
|:--|:--|
| **`REACHABLE`** | **到達可能なことが確認できている** |
| **`STALE`** | **エントリはあるが古い。次の通信時に確かめ直す** |
| **`FAILED`** | **問い合わせに応答が無かった** |
| `DELAY` / `PROBE` | 確認中 |

**「IP と MAC の対応を調べるコマンドを 2 つ」への答え**

| 選択肢 | 正誤 | 理由 |
|:--|:-:|:--|
| **`arp`** | **○** | **ARP キャッシュを表示する** |
| **`ip neigh show`** | **○** | **同じ内容を状態付きで表示する** |
| `route` | ✕ | **TCP/IP のルーティングテーブルの操作**。ARP キャッシュは扱えない |
| `iwconfig` | ✕ | **無線 LAN 関連の操作**。ARP キャッシュは扱えない |
| `netstat` | ✕ | **通信状態など様々な情報を表示する**が、ARP キャッシュは扱えない |

## 結果画面の見方

```bash
$ arp -n                               # 各欄の意味を見る
Address                  HWtype  HWaddress           Flags Mask            Iface
192.0.2.1                ether   02:fc:00:00:00:05   C                     eth0
192.0.2.99               ether   aa:bb:cc:dd:ee:ff   CM                    eth0
```

| 欄 | 意味 |
|:--|:--|
| **`Address`** | **相手の IP アドレス**（`-n` が無いとホスト名になることがある） |
| **`HWtype`** | **ハードウェアの種類**。Ethernet なら `ether` |
| **`HWaddress`** | **相手の MAC アドレス** |
| **`Flags Mask`** | **`C` は完成済み（Complete）、`M` は手で登録した静的エントリ（Manual/Permanent）** |
| **`Iface`** | **どのインタフェース経由で学習したか** |

**`arp -s` で追加したエントリは `CM` になります**（実機で確認）。
**`C` だけのものは自動学習、`CM` は手動登録**——ここで見分けられます。

**BSD 形式（`-a`）だと見た目が変わる**

```bash
$ arp -a                               # BSD 形式（実機で確認）
? (192.0.2.1) at 02:fc:00:00:00:05 [ether] on eth0
$ arp -e                               # Linux 形式（表形式。既定と同じ）
Address                  HWtype  HWaddress           Flags Mask            Iface
192.0.2.1                ether   02:fc:00:00:00:05   C                     eth0
```

**`?` はホスト名が引けなかった**ことを表します。
